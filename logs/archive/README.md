# logs/archive 历史归档（旧评测运行报告）

> 本目录只存放**已废弃评测协议**的运行报告与历史证据，禁止用于排序、调参或时间判定。
> 活动报告目录是 [`logs/official_eval/`](../official_eval/) 与 [`logs/execution/`](../execution/)。

| 目录 | 内容 |
|---|---|
| `legacy-evaluations-20260901/` | 旧 multi-model / sampled 协议的全部评估报告（c41–c89 系列、screen/full 等） |
| `legacy-official-eval-20260901/` | 早期官方形状协议报告（official-shape 前身） |
| `legacy-candidates-20260901/` | 早期候选分析（C39/C40 官方校准诊断、外部 v2.7 差距审计） |
| `legacy-root-files-20260901/` | 根目录清理出的旧临时文件（如 `solution_b0_tmp.py`） |

命名规范：`legacy-<主题>-<归档日期>YYYYMMDD`。归档动作记录在
[`docs/current-solution-status.md`](../../docs/current-solution-status.md) 第 7 节。
