## v162 判读（预注册解释表 S(v162) > 0 行触发）

1. **官方存在非零基础分或官方 STD 与本地 reference codec 定义不同**：本地 proxy 中
   标准 codec 对标准 STD 的 gain 恒为 0（v162 本地 288 case 全 0，逐位一致已验证），
   官方却给 1001。按预注册纪律，S(v162)=1001 只作锚点，不反推官方公式；
2. 后续判读：Δ_L = S(v163)−1001、Δ_A = S(v164)−1001、可加性
   S(v163)+S(v164)−1001 ≈ 17532（即 S(v163)+S(v164) ≈ 18533）；
3. **官方时间下界发现**：本地 API 2.6s 的解法官方 146s → 官方时间含 ~140s 级评测器
   自身开销。推论：
   - 有效算法预算 ≈ 300−146 = 154s；
   - v160 官方 232s 的算法份额 ≈ 232−146 = 86s；
   - v161 timeout 回溯解释：+28s 本地 gram refine 耗尽官方 68s 余量 → 该算子类
     官方/本地成本比 ≥ 2.4×；
   - v163/v164 官方时间上界 ≈ 232s（86s 全归一侧的极端情形），时间风险可忽略；
4. v162 目录名保持不变（非 RETAINED/REJECTED/TIMEOUT，锚点测量完成）；结果记录于
