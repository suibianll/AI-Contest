## 3. 关键事实与判读

1. **v084 = v086 = v158 的 Linear 逐 family 完全相同**（0.6211/0.4283/0.4749/0.3898）：

   - v084→v086 只改 Attention（+227）、v86→v158 只改 Attention（+117）；本地准确冻结复现；

   - 官方 Linear 侧对 v140 系的所有 Linear 提升 **零回报**，与本地等权把 v140 系排到 v86 之上的判断完全相反。
2. **负相关主要来自 q/k/v 窄层，不是 expansive 变换族**：

   - qkv 是本地抬升最大的 family（+0.125，三个 role 全部 >0.085），也是与官方负相关最强的 family（−0.63）；

   - fc（+0.008）与 proj（+0.022）抬升很弱，proj 负相关最弱（−0.20）；

   - 这**推翻了“负相关主要由 fc/proj 的本地变换收益造成”的预期**；也说明之前基于外部 hif4 的“q/k/v 不是修复目标”外部归因，与本地 proxy 的“q/k/v 提升最大”方向相反、都与官方相反。
3. 抬升集中在深层（L22/L14/L20/L11/L2），唯一 lo 更差的 L3/L21 反而是官方反向最小的层——本地浅/深层收益结构与官方无关。
4. **含义修正**（对 A2/A3 的预期调整）：

   - 即使 A3 transform 剥离把 v140 系得分拉回 \~0.52，也不能把负相关归因到某个变换族：本地假信号覆盖全 family，且 q/k/v 最烈；
