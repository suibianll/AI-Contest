## 评测边界

这是 hif4 仓库的 GPT-2 结构探针，不是官方复刻：固定脚本内置的 synthetic `TEXT`，
token 不足时重复；模型为 GPT-2 small（12 层、hidden 768、12×64 MHA）；`current`
配置由脚本在每个候选导入后统一覆盖私有参数。Linear/Attention 的标准基线由候选
`solution.py` 的私有 `_dense_to_hif4` / `_dequantize_hif4` 提供，因而只能做同脚本内
版本横向诊断，不能作为官方分数或独立标准。

## 趋势判断

- v84 → v86：Linear 完全不变、Attention `+0.0250`，与历史上 v86 仅改 Attention 的
  结构事实一致。
- v86 → v140：q/k 上升，但 fc/proj 下降，Attention 小幅下降；Linear 平均上升并不
  代表所有 role 或端到端官方分数都会上升。
- v140 → v147：Linear 完全不变、Attention `+0.0052`；与 v147 是 v140 Linear +
  v86 Attention 的本地组合事实一致，但不证明官方提交源码相同。
- 外部探针等权排序为 `v147 > v140 > v86 > v84`，官方已知排序为
  `v86 (16744) > v147 (16579) > v140 (15838)`；因此它仍不能作为官方排序器。

## 外部离线回归兼容性

同一外部仓库的 `test_solution.py` 对四个历史快照均返回非零，但失败原因是私有测试
接口与历史代码版本不匹配，而非 `real_data_eval.py` 的六个公开 API 无法运行：

| 版本 | 失败私有符号 |
|---|---|
| v84 | `_causal_attention_output` |
| v86 | `_causal_attention_output` |
| v140 | `dequantize_nvfp4` |
| v147 | `_linear_pair_transform` |

四个版本的 `real_data_eval.py` 均已完整跑到最终逐 role/Attention 汇总。该回归脚本不应
用于否定历史快照，也不应被改成候选私有实现的隐式兼容门槛。

## 决策

保留本日志作为 `hif4-external-gpt2` 交叉模型证据；不替换唯一主评测器
`evaluator/official_eval.py`，不据此晋级 v140/v147，也不把外部分数写入官方结果字段。
