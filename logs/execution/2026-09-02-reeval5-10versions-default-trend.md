## 3. 规律

1. **本地 Attention 与官方高度同序（Spearman 0.846），Linear 与官方负相关（−0.61）**。
   官方高分版本全部是 v86 系 Attention（v86/v157/v158，a≈0.7247–0.7358）；v138/v139/v140
   家族官方低分对应缩减 Attention（0.7223，低于 v86 0.7247），本地也能复现这个方向。
2. 三个明确的官方增量都与本地 Attention 上升完全同向：v84→v86（官方 +227 ↔ a +0.0153）、
   v140→v147（官方 +741 ↔ 恢复 v86 Attention，a +0.0024）、v86→v158（官方 +117 ↔ a +0.0110）。
   结论：官方分数主要跟随 Attention；本地 Attention proxy 排序可信，Linear 方向必须官方验证。
3. **本地等权 overall 不是官方排序器**：v140 系（本地 Linear 0.58）被本地排到 v86/v157/v158
   之上，与官方相反 → 任何 local Linear 高分都不能作为晋级依据。
4. **v157 首次补出本地 default**：Linear 0.516498（低于 v86 0.518759，−0.0023），Attention
   字段一致 0.724735；本地 o\_mean 也把 v157 排在 v86 之下（0.6033 < 0.6046），与官方
   （v86 16744 > v157 16729）同向。
5. 5 折校准使本地 weight calibration API 时间显著上升（v86 393.4s vs 旧 2 折 295.1s）；
   本地秒数只做同机诊断，不换算官方时间，官方 `<300s` 仍以回传为准。

## 4. 结论

- 后续优化优先级：冻结/提升 v158 Attention 的收益在本地方向可信；Linear 改进必须依赖
  官方回传，本地 Linear proxy 不可外推（官方隐藏结构 ≠ Qwen，见
  `2026-09-02-official-sample-vs-local-evaluator-audit.md`）。

- 既有父版本体系不变：v158（16861/223s）仍为本仓库最高可复现官方基线。
