# A4 full CAT-inspired BOAT-2 — rejected

日期：2026-08-30  
状态：`archived-rejected`；主代码已恢复 stable parent。官方评测当前不可用，
结果来自固定 Qwen2.5-0.5B cache / qwen-official shaped panel。

## 实现

候选在原有全局 BOAT parent 之外增加三层坐标搜索：

1. 每个 64-channel block 独立搜索 \(\alpha_b\in\{0,.25,.5,.75,1\}\)，
   \(d_{bj}=(RMS(A_{bj})/RMS(W_{:,bj}))^{\alpha_b}\)，再做全局几何均值归一化；
2. 在 identity、按激活 RMS、按权重 RMS、几何 RMS、high/low interleave 五种
   hierarchy-aware permutation 中选择 operand-local proxy 最优者；
3. 对正则化协方差
   \(C_A=A^TA/n+\lambda I\)、\(C_W=W^TW/m\) 做 CAT-inspired 广义方向
   \(v=C_A^{-1/2}u_{max}(C_A^{-1/2}C_WC_A^{-1/2})\)，用
   \(H(v)=I-2vv^T/(v^Tv)\) 作为每个 block 的 Householder 候选。

所有候选均只使用激活/权重各自的局部误差与二阶矩；部署时 activation 侧应用
与 weight 侧相同的正交变换，满足

\[
 A'=AD^{-1}O,\quad W'=WDO,
 \quad A'W'^T=AW^T,
 \quad O^TO=I.
\]
