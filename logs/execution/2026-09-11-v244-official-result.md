## 这次官方做了什么（这是本记录最重要的一条）

**它把"逐字节等价"这个类别第三次放到官方侧验证，并且是迄今最强的一次。**

| 版本 | 类别 | 官方读数 |
|---|---|---|
| v233（L-TF1） | 等价 + 提速，K=1 父 | `18428 / 288s`，相对 v230 **同分 / −4s** |
| v237（L-TF2） | 等价 + 提速，K=2 父 | `18518 / 289s`，相对 v231 **同分 / −2s** |
| **v244（A-TG1）** | **等价 + 提速，Attention 侧** | **`18518 / 276s`，相对 v237 根 同分 / −13s** |

三张的**分数都恰好等于父**——这正是等价性预测的东西，官方以完全相等的分数把它兑现了。
本次的量级（−13s）比前两次（−4s、−2s）大一个档次，因为本卡省的是**全窗注意力前向**，
而前两张省的是**梯度复用的首遍**与**循环不变量重算**。

**一处必须写明的限制**：v244 的 276s 与 v237 的 289s **各只测过一次**。按 AGENTS §2，
官方秒数带未量化的波动，**不反推计时方差、不推导换算系数、不做"还差 N 秒"的预算**。
−13s 是**两个官方读数之差**，作为事实记录；它不构成任何后续候选的研发预算或优先级依据。

**本次还把观测区间拉宽了，这一条要写在前面**：同一棵树上的单次官方读数此前散在
**288–292s**（v230 292 / v231 291 / v233 288 / v237 289，跨度 4s）；v244 的 276s 把区间拉到
**276–292s，跨度 16s——比该卡自称省下的 13s 还大**。每个版本只测一次，
**候选差异与计时方差无法分离**。所以：
- **−13s 记作事实，不作为"这个机制值 13s"的定价**；
- 也不能反过来用它证明"官方计时方差有 16s"——方差同样**从未被测过**（重复相同 SHA 被禁止）；
- **不据此预测任何候选进不进 300s**，包括 v245 与 v248。
