## 判读

1. **修复方向有效但不达标**：A21-1 的官方 −206 中有 92 分来自"删除旧训练"
   的回退损失；A22-1 用完整 R3 回退追回了这 92 分。但 scale 提案在官方上的
   净贡献仍为负（−114），说明 3 个接受层（L8/L12/L23）的本地增益
   （+0.0871/+0.0508 组均值）不能转化为官方分。
2. **同族 proxy 反转第二次发生**：A22-1 本地 ID +0.005786、OOD +0.002841、
   双 split 正、全部合法性/时间门通过，官方仍 −114。与 A21-1（本地 +0.001234
   → 官方 −206）同向。R3 父上的**替换式** scale 提案族（gate 对 B 或 gate 对
   P + 完整 R3 回退）两次官方负向，该族关闭，不再以任何 gate 变体重试。
3. **时间模型残差**：273 − 239.850 = **+33.150s**，与 A21-1 的 +24.716s 同向。
   训练类校准的官方成本被六 API 时间模型系统性低估；两个样本不足以重拟合，
   仅记录。任何后续训练类候选的官方时间评估须考虑该方向残差。
