## 3. 判读一：三个变体是**官方确认的 no-op**，不是"幅度小"

v190 / v191 / v194 的分数**逐位等于**基线 14405（不是接近，是相等）。三个机制在官方侧被证伪：

| 版本 | 侧隔离分 | 本地证据（与官方一致） | 完整包官方结果 |
|---|---|---|---|
| v190 | 14405（0） | gate 拒绝、`diag_accepted=0`、shard0 paired `0/0/12`、delta `0` | `TIMEOUT` |
| v191 | 14405（0） | 主奇异值约 `1e-11`，方向本身退化 | `TIMEOUT` |
| v194 | 14405（0） | 与父逐位等价（本就承诺无精度变化） | `18032/285s`（同分 +5s） |

v194 的 0 分是**预期内**（它就是等价提速卡），但它同时暴露了下面第 5 条的时间问题。

## 4. 判读二：v192 / v195 有真实正向，但只有 +22 / +21

- **v195 的 +21 被两个独立口径交叉验证**：侧隔离 `14426 - 14405 = +21`，完整包
  `18053 - 18032 = +21`。同一增益在两个口径下重复出现 → 是真实信号，不是噪声。
- 这同时**第一次用官方数据直接证实了侧向可加性**：Attention 侧 +21 → 完整分 +21，1:1 转移。
  这是本批数据唯一的结构性正面收获。
- 但幅度只有 **0.15%（21/14405）**。

## 5. 判读三：标准 Linear 侧隔离时间**对完整根时间没有预测力**

| 版本 | 侧隔离 Δtime | 完整包实际 |
|---|---|---|
| v194 | **−4s** | `285s`，比父 280s **+5s** |
| v190 | 246s（推 ~288s） | `TIMEOUT`（>300s） |

两个方向都不对。**侧隔离只能测分，不能测时间；时间仍只能在完整包上实测。**
这与 v194 已有的结论（本地 calibration API −22.5% 未转化为官方提速）同源。

## 6. 判读四（核心）：对"当前优化是否没有实质性提升"的回答

**是，当前优化路线没有实质性提升。但归因必须精确——不是"时间墙挡住了大收益"。**

我上一轮的判断（"机制有效但被时间墙阻断"）**需要修正**：v195 用 +5s 换 +21 分，证明在
当前余量下时间**不是**唯一约束；**这些机制自身的天花板就在 +20 分**。

量化三条：

1. **整条 Attention 优化线的累计官方收益 ≈ +21 分。**
   从 R3 `14405` 到 v195 `14426`，历经 A2 rotation、K-center、互逆对角、块三角输运、
   STE 全矩阵残差、梯度聚合修复——累计 +21。
   Attention 互逆/残差族八个变体的官方结局：
   `0 / 0 / +22 / TIMEOUT / TIMEOUT / TIMEOUT / TIMEOUT / TIMEOUT`（v190/v191/v192/v196/
   v198/v199/v201/v203）。

2. **缺口与速率差两个数量级。**
   当前完整根 `18053`，距用户确认的榜首锚点 `21765` 差 **3712 分**。
   - 按最优效率 4.2 分/秒 × 剩余时间余量 19s → 时间最多再换 **约 80 分**；
   - 按机制维度 21 分/机制 → 需要约 **180 个**同量级机制。

3. **我们尚未复现 21071 锚点的机制。**
   外部确认的成功机制（A@W 拟合 + Q/K 互逆 scale 学习）拿 `21071/283s`，我们 `18053`，
   差 **3018 分**。而我们复现出的"Q/K 互逆"族只值 +21 → 说明**实现形态不对**，不是机制名不对。
   Linear 侧 A@W 拟合两次尝试均未落地：v197 官方 `17277/285s`（−776）、v204 与 v202
   **逐位相同**、无 hard-output 增益。

## 7. 由此产生的边界（写入时需遵守）

- **关闭机制族，不只关闭实现**：v190（逐通道互逆平衡）、v191（块三角输运）
  已被官方精确零增益证伪；v194（校准等价提速）侧隔离 −4s 但完整包 +5s，提速路线不成立。
- **v192 的 +22 有效但不可部署**：完整包 TIMEOUT；+34s 的时间成本在余量 19s 的根上无解。
  只有先降时 ≥40s 才可能回收，且回收后只值 +22。
- **标准 Linear 探针继续只用于测分**，任何基于它的时间推断都不写进晋级或否决理由。
- 上述关闭只针对这些具体实现与其直接邻域，**不**推广为"Attention 侧已饱和"或
  "互逆重参数化无效"（与 LC1/LC2 审计同一条纪律：关闭什么就写什么）。
