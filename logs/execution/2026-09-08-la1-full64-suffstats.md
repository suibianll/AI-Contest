# L-A1 Full-64 时间重构：充分统计量 + 增量接受（2026-09-08）

依据用户纠偏指令 §八（时间优化从算法结构做，保持 Full-64 数学能力）。

## 实现（L-A1，从 L-A0 改进）

- **充分统计量预计算**：`G = XwᵀXw`（d×d）、`C = XwᵀYw`（d×o）一次构造；
  每块 `H_B = G[sl,sl]+λI`、`G_B = C[sl,:] − G[sl,:]Wᵀ`（无需每块重算 XᵀX/XᵀR）
- **增量残差接受**：维护加权残差 R，接受块后 `R ← R + Xb(W_old−Wq)ᵀ`，
  `L_cand = ||Rcand||²`（避免每块全量 `X@W` 重算）
- **Full-64 数学不变**（不 rank-8），只改实现

## 结论

1. **时间重构有效但不足**：calib_w 272→245s（-10%），但六 shard 全量校准
   ~1470s（8.75s/state × 168）仍远超 300s。**Full-64 逐块求解在结构上无法进 300s**。
2. **过拟合确认**：gain 0.03（校准 S_fit=1.0 但独立窗口崩）。已知 0.88 官方方法
   必有 L-A0/A1 未捕捉的结构/正则/目标差异。
3. 按用户指令 §九 C"首个代表版本允许本地 API 时间较高用于确认机制"：
   **Full-64 校准能力已确认**（S_fit=1.0），但时间与过拟合需根本性解决。

## 方向判断（与已知 0.88 方法的差异）

已知可达 0.88（官方 50 Linear case）的方法，其核心机制可能包括：
- **强正则/隐式低秩**：L-A0 无约束解在 N=138 上记忆（23.6M 参数 vs 138 行）
- **不同的条件更新**：GPTQ 式逐坐标/逐块条件求解（非整块 Full-64 一次解）
- **官方 50 case 与本地 336 独立窗口不对应**（本地 gain 0.03 不代表官方）
