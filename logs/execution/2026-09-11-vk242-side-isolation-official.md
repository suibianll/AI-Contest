## 3. 这条回传关闭了什么（机制级，不只实现级）

VK 机制此前**一个官方分都没有**——完整包 v241/v242 两次 TIMEOUT、侧隔离 v241 TIMEOUT，
四次尝试拿不到任何数字。**本次拿到了，而且它直接回答了这个机制在官方侧值多少分：
不是"值 0 分"，是"倒扣 307 分"。**

侧隔离是**单变量**口径：与 R3 基线共用同一个标准 Linear codec（逐字节同一实现，
见 `2026-09-11-vk-side-isolation-probes.md` §3），唯一差异是 Attention 侧换成 VK。
所以 `−307` 是该 Attention 机制的官方效应。

**关闭范围（写清关闭什么）**：

- 关闭 **V 侧相对位置核加权选 V 码**这一机制，含**两个已测粒度**——per-Q-head（v241）
  与 per-KV-group（v242）。两者的共享版是**代数重参数化**（同一最小化点，本地面板均值差 `6e-5`），
  故本次测量的粒度差异不构成两个不同机制。
- 关闭其已测参数邻域。**不缩核半径/窗口/候选数/粒度重试**。
- 关闭**该机制的降本工作线**：见 §5。

**不关闭范围**：

- **不推广为"V 侧码分配整族无效"或"位置/内容信息不能用于选 V 码"。** 被官方定价证伪的是
  **"相对位置核对 V 码选择"这一具体形式**。更宽方向的任何后续尝试都需要一个**新的**机制，
  而不是对本次形式调参。
- 不改变 AGENTS §3 中 2026-09-10 的**校准期 V 码分配授权**（该授权针对的是码分配/求解算法，
  与本次机制无关，仍然有效）。
- **不关闭 VK-1 之外的任何东西**；本记录不对 Q/K 侧作任何推断。

## 4. 它同时证伪了什么：本地面板六片全正 → 官方 −307

这是本次最需要写清楚的一条。

| 本地 4B 面板，v241 | 六 shard **全部为正**，均值 **`+0.004547`**，`6/6` |
| 本地 4B 面板，v242 shard0 | **`+0.005159`**，`12/0/0` |
| **官方侧隔离** | **`−307`（−2.13%）** |

**本地读数说正向，官方说大幅负向——不是幅度不够，是方向相反。**
VK 卡正是以"六片全正"作为机制有效的依据推进到官方提交的。

这与 AGENTS §2 已有的两条同源，但现在强度更高：

- v229 本地 `+0.014923` → 官方 **−2**（幅度反转，方向也反转）；
- **v242 本地 `+0.005159`（shard0 12/0/0）→ 官方 `−307`。**

**推论：本地面板的"全 shard 同号"不构成官方方向的证据。**
本地读数只作机制诊断、不设提交或晋级阈值（AGENTS §2）这条纪律，
本次是迄今最强的支持案例。

**不解释成因。** 本地与官方在数据、参考、聚合口径上的差异可以有很多种组合，
本记录不做机制归因——没有测量支持任何解释，写了就是推测（证据等级 D）。

## 5. 对时间线的意义：VK 的降本工作线已无意义

v241/v242 完整包两次 TIMEOUT 之后，仓库围绕 VK 的下一步讨论集中在**降本**：
per-Q-head（16 核）→ per-KV-group（4 核）、偏移循环向量化、核半径 15 → 7。
v242 的侧隔离探针正是这条降本线的产物，本地实测 V API 成本确实降了 **6.4×**
（`0.591` → `0.092 s/次`），官方时间也确实从"超时"落到 `250s`。

**但精度账已经结算：即使把它塞进 300s，它也会倒扣 307 分。**
所以对 VK 机制而言，**"能不能进限"已经不是待解的问题**——进限不改变负向。

**本文由此得出一个方向性结论（对本机制，不外推）**：
VK 的降本线**到此为止**，不再为让该机制落地而做时间工作。
这不影响其他机制的降本工作——那条纪律（AGENTS §2：降时的意义是让有分的机制有机会落地）
本身正是靠这个案例说明为什么必须先有分。

## 6. 不能由此得出的结论

- **不能说 v241 完整包若进限会得多少分。** 未测。侧隔离分不晋级、不与完整分相加或互推（AGENTS §2）。
- **不能用 `250s` 与 v241 侧隔离超时去反推官方计时方差或成本倍率。** `>300s` 与 `250s`
  之间差多少不知道，v241 侧隔离没有返回数字。
- **不推导本地→官方换算系数。** §4 的两条读数恰恰说明这个换算不稳定（同号反转 + 幅度差两个量级）。
- **不由此宣称 Attention 侧已饱和**，也不推广到其他机制族。
- **不重提交任何同 SHA 或逐位等价候选。**
