# v141 BDLR-JAQ rank-4 execution

The v141 source was archived and committed before the full run. It added four calibration-selected off-block columns of `H=Q(W)^TQ(W)` and `D=Q(W)^TW` to the existing block activation gradient. The additional products did not increase Attention work.

The complete `official-shape-v1` run returned Linear `0.2817598810465049`, Attention `0.7159419612310174`, API `204.6810824975837 s`, and wall `228.12701109994669 s`. The time objective remained inside the local proxy, but the precision objective failed badly. The implementation is retained as an immutable rejected archive for diagnosis; v142 changes only the update rule by freezing the selected low-rank anchor coordinates.
