# 低维 A@W 拟合：机制分析与实验证据（用户 21071 机制线索）

> 日期：2026-09-07。run_id：`l21-2-lowdim-probes`。侧：Linear。
> 来源：用户确认外部 21071 机制 = A@W 拟合 + Q/K 互逆 scale，Linear 分项约
> 4400/5000（平均 0.88）；官方 50 Linear 样例。

## 1. 机制设计：什么是"低维空间 A@W 拟合"

目标：在合法 HiF4 权重空间内最小化 `Σ_f ω_f ||Q(X_f)W − X_f W_origᵀ||²`。
直接的全维逐块求解（L21-1/L21-2）在本地 holdout 全部退化。降维是关键：
**把权重更新限制在低维子空间**，减少对校准文本特定模式的吸收。

三种已实现形式：

| 形式 | 子空间 | 求解 | 本地 holdout 结果 |
|---|---|---|---|
| v1 逐块激活 Gram（rb=8） | 每 64 块 `G_B=XhᵀXh` top-8 特征方向，`ΔW=ΔB·Uᵀ` + snap 父格点 | 闭式 `ΔB=solve(AᵀA+λI, AᵀR)` | o **−1.3% 改善**；proj +10.5%；fc_up +5.9% |
| v1 rb=16 | 同 top-16 | 同 | o +2.0%；proj +22.6%；fc_up +10.0%（更差） |
| v2 逐块 + 完整重量化 | 同上，连续候选走 `_dense_to_hif4` 重新生成层级 | 同 | o +7.8%；proj +50.5%；fc_up +17.6%（更差） |
| v3 权重 SVD 全局低秩（rb=8） | `W_orig` SVD top-8 左右奇异，`ΔW=U_r B V_rᵀ` 全局 | 闭式 `B=solve(AᵀA+λI, Aᵀ R U_r)` | o +66%；proj +53%；fc_up +37%（更差） |

**结论**：
- v1（逐块激活 Gram + snap 父格点 + rb=8）是唯一在 o 层改善的变体，且 proj/fc_up
  退化幅度（+10%/+6%）远小于全维（+78%），方向正确但未收敛。
- v2/v3 失败因为：完整重量化在原 W0 上叠加的重编偏离父部署语义更远；全局
  SVD 低秩破坏块内层级共享结构。

## 2. 为什么本地 holdout 退化而官方可能 0.88

**官方 50 样例与校准集同分布**（同文本建模范畴）→ 校准集上拟合好的 W 在官方
样例上同样好，无分布外惩罚——这正是"撒谎"（利用官方评测与校准同源的事实）。
**本地 eval-v3 holdout 是刻意分布外**（validation/test 不同窗口）——任何
吸收校准文本模式的权重在此必然退化。

这解释了：
- 全维 L21 本地 3/3 退化、但用户外部 A@W 拟合法官方 0.88；
- v1 rb=8 o 层改善：o 层激活稳定，低维拟合泛化好；fc/proj 大形状桶行数少，
  校准容纳的激活模式不足以支撑子空间（仍过度局部）。

## 3. 可部署边界与下一步

按 AGENTS：官方样例与校准同源是用户事实，本地 holdout 独立验证是本地规则。
若要让该机制"本地 holdout 也不退化"，需要拟合目标的分布稳健化：
1. **加 fold 交叉验证式子空间**：只从 fold 0 提子空间方向、fold 1 校验 ——
   减少单窗口过拟合；
2. **低维方向用多fold 聚合的 Gram**（median/worst-fold）而非单窗口；
3. **子空间秩自适应到各行数**（fc/proj 行少 → rb 更小），但这是参数邻域，
   不能扫 → 需固定规则（如 rb=min(8, N/16)）另立卡。

v1(rb=8) 是目前唯一有正向记录的形式，可考虑扩展为完整候选（shards0,2 多
case 统计）验证其符号；若多 case 稳定正向才值得继续。不因当前 3 代表 state
负向就关闭低维拟合族。
