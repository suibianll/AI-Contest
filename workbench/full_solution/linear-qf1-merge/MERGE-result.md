## 关键发现：A-RB2 解锁了层 0 的 A-GR1

插桩四个模块（v250 / candidate2=v250+A-RB2 / v252 / v253），层 0：

| 模块 | 旋转 winner | A-GR1 arm |
|---|---|---|
| v250 | 无 | — |
| v250 + A-RB2 | **block 256** | — |
| v252（+A-GR1） | 无 | parent |
| **v253（+A-GR1+A-RB2）** | **block 256** | **accepted** |

block 256 的旋转改变了 base 状态，使 A-GR1 的训练窗口 gate 从 **parent 翻成 accepted**，
两项效应复合：层 0 面板 +0.011304（10/2 正），远大于 A-RB2 单独在 v250 上的 +0.001102。
层 5/22 的 A-GR1 arm 不受影响，读数与 A-RB2 单独一致（层22 由 +0.001530 变 +0.001132，
是 A-GR1 已 accepted 状态下的重定价——以本链的 paired 读数为准）。

**结论：机制效应不可加，必须逐个在最终链上重新定价。** 本卡每一步都用了同链 paired 面板。
