# A-RB：C76.4 候选集沿 block 轴扩展 —— 三个读数，全部不发货（2026-09-11）

**结论先行：Attention 侧本轮四次尝试全部不发货。** 其中三次有明确机制解释，
一次是正增益但增益/代价比太差。**Attention 面板保持 0.5340。**

---

## 为什么试 block 轴

`C76.4`（旋转候选搜索）是本项目**价值密度最高**的 Attention 机制
（官方定价：关掉它 −84 分 / −6 秒）。其搜索空间是

```python
for block_size in _ATTN_ROTATION_BLOCKS:   # (16, 32, 64)
    for seed in _ATTN_ROTATION_SEEDS:      # (0, 1, 2, 3)
```

A-TR1 已证明 **seed 轴是退化的**（seeds 0/1/2 的 sign 向量逐位相同，seed 3 只差 1 位）。
所以候选集的**真实多样性只能来自 block 轴**。head_dim = 256，合法 block 为
`4, 8, 16, 32, 64, 128, 256`，而候选集里**只有 16/32/64** —— 最细的两级与最粗的两级都缺。

## A-RB1：加最细的两级（4, 8）—— **精确的 0，且可解释**

`_ATTN_ROTATION_BLOCKS = (4, 8, 16, 32, 64)`，shard 0 对 v250：

```
cases 12   delta_mean 0.000000   +0 / −0 / 0 12
decision: reject ['attention: delta_mean=+0.000000 <= 0']
```

**12/12 逐例恰好为零** —— 不是"变小"，是**完全不动码**。原因与本项目既有的
§4.5 结论一致：**4 与 8 恰好是 HiF4 自己的 `scale_lv3`（per-4）与 `scale_lv2`（per-8）
组宽**，在这两个块宽内的正交变换**被该组自己的标度吸收**，因此不改变任何码。
**这一条是结构性的，不是经验性的。**

## A-RB2：加最粗的两级（128, 256）—— **正的，但太小**

`(16, 32, 64, 128, 256)`。128/256 **跨 64 块边界**，因此会动码（与 4/8 相反）。六 shard：

| shard | 0 | 1 | 2 | 3 | 4 | 5 | 均值 |
|---|---:|---:|---:|---:|---:|---:|---:|
| delta | +.001102 | 0.000000 | 0.000000 | 0.000000 | +.001530 | +.001285 | **+.000653** |
| +/−/0 | 7/5/0 | 0/0/12 | 0/0/12 | 0/0/12 | 9/3/0 | 8/4/0 | **24/12/36** |

**六片里三片恰好为零**（那两个 block 在那三片覆盖的层上从未赢过择优）。

**不发货的理由是增益/代价比**：新增 2 个 block × 2 个不同候选 = 每层多 **4 次**
`_attention_deployed_mse` 调用，本地 CPU 路径约 **+2.3 s/层 ≈ +12% 校准耗时**，
换 **+0.000653** 面板增益。对比：v248/v250 的 L-EM 加轮次是 **+0.017 / +12.8%**。
**用官方 24 s 余量换 +0.0007 是坏交易。**

## 一条结构判断（供下一轮）

**Linear 能做 L-EM、Attention 不能，差别是结构性的，不是没想到：**

| | 目标 | ΔX 的度量 | 是否输入相关 |
|---|---|---|---|
| Linear | `O = X Wᵀ` | `Wᵀ W` | **否** —— 可校准期编译进 state |
| Attention | `O = A V` | V 要 `A`；A 要当前的 Q、K | **是** —— 三个动态 API 各自只拿到自己的操作数 |

所以 Linear 有"精确度量上的单调下降"这条富矿（L-EM，官方 +375/+90），
而 Attention 的同一形状**在部署端拿不到度量**。CM-1（Q 侧编译近似度量）已测为
NO_EFFECT，VK（V 侧位置核代替 A）官方 `−307` —— 两者都是这条结构约束的实例。

**这不等于"Attention 无路"**，但它解释了为什么 Attention 侧的收益一直在
`+0.001 ~ +0.005` 一档，而 Linear 侧一次改动就是 `+0.017`。
