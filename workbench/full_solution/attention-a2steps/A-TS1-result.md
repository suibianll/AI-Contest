# A-TS1 结果：A2 训练步数**不是** Attention 侧的 K（2026-09-11）

**结论先行：`_A2_TRAIN_STEPS` 32→64 在面板 shard 0 上为 `−0.001654`（7 正 5 负 0 零，decision=reject）。
候选未归档、未推送；根不受影响。**

---

## 为什么试它

Linear 侧刚刚证明「把已有的下降推得更远」是本项目最有效的动作：`_EM1_PASSES` 3→6
在六 shard 上给 `+0.016661`（286 正 / 50 零 / **0 负**），累计对根 `+0.030061`。

Attention 侧的名义对应物是 A2 旋转训练的 Adam 步数（`_A2_TRAIN_STEPS = 32`），
且 A2 gate 目前**六层只接受五层**（层 8 拒绝），步数推高理应既提高已接受旋转的质量、
也可能改变接受集合。

## 为什么和 Linear 相反（这是本条的要点，不是借口）

**两个"轮数"优化的不是同一种东西：**

| | L-EM 的 `_EM1_PASSES` | A2 的 `_A2_TRAIN_STEPS` |
|---|---|---|
| 优化对象 | **精确的部署目标**（`2⟨δ,g⟩ + δᵀGδ`，即真实输出 MSE 的二阶展开） | **训练代理**（fit 窗上的 attention 输出 MSE） |
| 接受规则 | **单调**：只在代价下降时接受该步 | 训练损失单调下降，但**另有独立 gate**（gate 窗 `calib_qkv_list[-1]` 上 `loss_rotation < loss_identity`） |
| 加轮次的后果 | 目标继续下降，**弱支配**（不会更差） | fit 窗上更好、**gate 窗上可能更差**（过拟合） |

所以 L-EM 加轮次近似**免费**（单调下降 + 只在下降时接受），而 A2 加步数会
**过拟合 fit 窗**。本卡的负结果与该解释一致。

## 对下一轮的意义

Attention 侧要复制 Linear 的成功，**不能靠"把训练推得更久"**，必须找
**在同一目标上单调、且只在真实输出改善时接受**的下降——也就是 A-GR1 那一类
（v246 已在等官方定价）。**"训练更久"这条路在 Attention 侧是关闭的**（本卡实测）。

## 口径

- 面板 shard 0 **仅 12 例**，且本地面板对官方无预测力。所以严格说，本卡证明的是
  「本地方向为负、decision=reject」，**不是**「官方一定更差」。
- 但按纪律，**负的本地读数不推进**：不跑六片、不归档、不提交。
- 未测其他步数（16 / 128）——按 #40 的纪律，**"改动值"的邻域扫描不是收益来源**；
  且本卡的机制解释（过拟合 fit 窗）预测邻域内也不会有正收益。
