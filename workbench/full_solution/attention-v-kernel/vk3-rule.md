（"诊断后完成一个固定配置的部署表达式与校准选择规则"）。

脚本 `vk3_rule.py`（GPU，`.venv`）；原始输出 `vk3-rule.out`；结构化读数 `vk3-rule.json`。
**本卡不设阈值、不下判决**（计划 §6.1）。

## 规则

只改**权重**，其余与 `v_error_balance.py` 同型：

```
UNIFORM   min  Σ_c Σ_t ( Σ_k (1/T)·δ[k,c] )²                 （历史实现，曾测 +0.0038）
KERNEL    min  Σ_g Σ_{h∈g} Σ_t ( Σ_k w_h[t−k]·δ[k,c] )²      本卡
```

`δ = V̂_hiF4 − V_ref_nvfp4`，两端在部署期都可见（V API 同时拿到 NVFP4 输入与自己产出的码）。
`w_h`（32 个参数 × 每 Q head：`|k−t| ≤ 15` 的 31 个带状权重 + 1 个远桶）**只在 fit 窗（0,1,2）上拟合**。

**求解**：目标是二次型且**按通道可分离**，所以单元素改动的目标变化是**精确闭式**：

```
ΔJ_i = g_i·ε + ε²·Q_ii        g = 2·Σ_h W_hᵀ(W_h δ)      Q_ii = Σ_h (W_hᵀW_h)_ii
```

每轮各通道取最优单步、同时施加（通道间独立，不互相干扰）。`W_hδ` 是带宽 32 的带状卷积，
用 `unfold` 实现为 `O(T·C·32)`，**不物化 T×T 矩阵**。

## 两条独立检查（先于任何数字）

| 检查 | 结果 |
|---|---|
| 带状卷积 ≟ 显式 Toeplitz 矩阵 | **max\|gap\| ≤ 2.0e-15**，12/12 窗 |
| `to_dense(父码)` ≟ `dense(pv)` | **max\|gap\| = 0.000e+00**，12/12 窗（逐位） |

第二条是**必须的**：在它加上之前 uniform 报出 "+138%"，我一度怀疑评分路径有错；
加上后数值完全不变，证明那是真实读数。

## 本轮抓到的两处缺陷（过程记录）

| # | 缺陷 | 症状 / 抓法 |
|---|---|---|
| 27 | 单 token 扰动使四个预测器全部退化成 `‖δ‖²`（`mean_k δ = δ[k]/T`） | VK-2 里 `rho(U,A) == rho(I,A)` **完全相同**——"太整齐"本身就是信号 |
| 28 | `base_code` 在 mantissa 单位（0–1.75）却按 ±1.0 步进 = ±4 个码位，clamp 后**把码打到饱和** | uniform 报 "+138%"；抓到的方式是**先算真值、再看动了多少码**——1% 的码移动不可能换来 138% 的变化 |

## 这一卡支持什么、不支持什么

**支持**：在**留出校准确认窗**上，核加权 V 码选择让**真实 attention 输出 MSE 平均下降 1.17%**，
且量测管线有两条精确的独立检查。

**不支持**：
- **不是面板结论。** 这是 12 个校准留出窗上的 V 侧单机制读数，不是 72 例面板，不构成官方收益主张。
- **未做候选**——没有编译进 state、没有六 API 自包含验证、没有 shard。下一步才是这些。
- 不代表 K 侧或 Q 侧可用同一结论（Q 侧 CM-1 已给 NO_EFFECT；K 侧未测）。
