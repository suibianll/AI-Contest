## 3. 改变什么

校准期（`hif4_calibration_attention` 内）：在 base stack B 坐标上训练对称互逆旋转
`E = exp(S)`（Q）、`F = exp(−S)`（K），GQA 每 KV 组一个 S(g)（4 Q 头共享）；
部署调用图不变——`learned_rotation` 存入 state，动态 Q/K API 执行编译好的规则
（与 A21–A25 同一插入点）。V、center、multiplier、rotation、block-smooth 全部冻结为 B。

训练目标（新）：**锯齿符号 × 三角幅度的网格残差输出误差模型**
`L(S) = Σ_w ‖Q_b·ε̂_kᵀ + ε̂_q·K_bᵀ − ε̂_q·ε̂_kᵀ‖²_F / (T·d)`，
其中残差模型 `ε̂ = (Δ/2)·|sin(πy)|·sgn(frac(y)−0.5)`（y = x/Δ，Δ = 0.25·块 amax，
S=0 预计算并 detach），Q_b = T(Q)、K_b = T(K) 为 B stack 变换后浮点。
这是 **F2 输出效应** `‖attn(Q̂,K̂,v̂) − attn(T(Q),T(K),v̂)‖²` 的一阶可微代理。
> 实现修正记录（R-4 步骤 1 数学验证产出）：初版用首项正弦 `ε̂ = (Δ/π)sin(2πy)`，
> 验证 V4 暴露半点伪吸引子（sin(2π·半点)=0 ⇒ 模型把半点当码点，真实残差却最大）；
> 修正为锯齿符号×三角幅度模型：码点 ε̂=0 且梯度最大、半点 |ε̂|=Δ/2 最大（被推离）、
> 每单位区间符号与真实舍入锯齿一致（保留 Q×ε_k 交叉项的符号相关）。判据与配置不变。

## 4. 为什么可能有效

1. A0 证据链：A25 scale proxy 压幅 30%+ 官方 −380（幅度自由度饱和）；amax 家族不含相位项（信号相对码网格位置），旋转是唯一可移动相位的合法自由度。
2. 残差模型结构匹配真实舍入：码点处 ε̂=0 且梯度最大（推离响应强）、半格处 |ε̂|=Δ/2 最大且符号跳变（次梯度推离，无伪吸引子）、每单位区间符号与舍入锯齿一致 → 最小化 L 把块内值推离半格、贴近码点 → 最近邻码字真实翻转（幅度×相位双重作用）。
3. 账本证明 F2 = 0.192 是 QK 误差全部且 OPEN：压 F2 直接传导到 F4（0.468 → 0.275+Δ）。
4. 梯度非零保证：ε̂ ≢ 0 且 ∂ε̂/∂x̃ = 1 − cos(2πy) ≢ 0；互逆 float 主路径抵消只发生在 Q_bK_bᵀ 项，残差交叉项携带非零梯度（A24 死路仅适用 STE 恒等 ε≡0）。
