## 1. 跨模型探针（GPT-2 / opt）作为官方方向旁证 —— **废弃**

**原始位置**

- `AGENTS.md`（计划候选 C1 条目）："`本地 default −0.004450 / GPT-2 −0.002753 / opt −0.021851 方向一致`"
- `AGENTS.md`（v161 条目）："本地全漏斗通过（…、**GPT-2 同号**、D1 满足…）"
- `docs/current-solution-status.md`（v174/v176 段、v165 段、v161 段）：同上三处
- `docs/direction-map-and-aw-fitting-lessons-2026-09-02.md` §"可外推的边界"表格：
  "`GPT-2 跨模型探针 | v140 > v147 > v86（三对全反转）`"
- `solutions/20260903_v161_*/result.md`：GPT-2 同号作为漏斗通过项

**为什么失效**

2026-09-04 对全部有官方回传版本做了探针排序与官方排序的相关性检验：

| 探针 | 与官方排序的 Spearman ρ |
|---|---:|
| GPT-2 | **−0.071** |
| opt | **−0.200** |

两者**不携带官方排序信息**（ρ 接近 0 且符号为负）。历史上"GPT-2 同号、opt 同号"被
反复当作正向旁证，是**选择性引用**：v161 用 GPT-2 同号支持晋级，结果官方 timeout；
v176 用三模型方向一致支持 C1，结果官方 −41。

**取代结论**

跨模型探针**只作机制鲁棒性描述**，不得作为晋级旁证、不得写入"漏斗通过"条件、
不得用于否决或支持候选。

**执行含义**

v161/v176 条目中"GPT-2 同号"的措辞应理解为"当时的记录事实"，不构成通过证据。
今后本地漏斗只保留：接口、合法 state、有限输出、机制 reachability、非目标侧
control 不变、以及 R2 门禁（§5.2）。

## 2. 跨模型作为强制门禁 —— **降级为记录项**

**原始位置**

- `AGENTS.md` 评测步骤 7："**跨模型泛化记录**：…`gpt2` 为强制验证，最终候选再使用一个
  不同架构的本地 `pythia-160m` 或 `opt-125m`…"
- `AGENTS.md` 晋级检查项："收益若集中在少数 layer/role/fold、**依赖单一模型形状**，
  或 control 发生变化，按过拟合处理。"

**为什么需降级**

既然探针与官方排序 ρ ≈ −0.07 ~ −0.20，"Qwen 正向而跨模型整体负向 → 标记
`model-specific-risk`"这条推理链的**前提不成立**：跨模型负向本身不携带官方风险信息。

**取代结论**

跨模型运行**保留为记录项**（仍运行、仍写入日志），但：

- 不得作为晋级/否决门禁；
- 不得用于标记 `model-specific-risk`；
- 真正的过拟合判据是 **`L1`（逐 case gain 平均绝对变化）**，见 §5.2。

## 3. "提交前本地 API ≤ 240 s" —— **废弃**

**原始位置**：`docs/direction-map-and-aw-fitting-lessons-2026-09-02.md` §7 决策纪律第 3 条

**为什么失效**

240 s 是从"v129 本地 248 s 官方仍 timeout"单点外推的安全边际，没有利用 API 时间结构。
本地总时长同官方时间只有 R² = 0.432（MAE 18.6 s），据此设阈值会同时误杀
（v183 本地 279 s 官方 279.7 s 通过）和误放（v161 本地 +28 s 增量却耗尽 68 s 余量）。

**取代结论**

用六 API 分解预测（21 个版本）：

```
T_official ≈ 170.3 + 0.1154·W_calib + 0.6939·A_calib + 0.7344·dyn_act − 1.5837·dyn_qkv
R² = 0.799, MAE = 10.1 s
```

判据：**预测官方时间 < 280 s 才提交**（300 s 硬限 − 2×MAE 余量）。
模型对最新版本系统性低估（v182 残差 +21 s、v183 残差 +19 s），余量不能省。

**⚠️ 即时应用**：未提交候选 **v184** 预测 **322.5 s**，即使保守修正仍 ≈ 315 s，
**超时风险极高，不建议提交**。

## 4. 单变量"本地 API 总时长 → 官方时间"（ρ = 0.874）—— **废弃**

**原始位置**：`docs/direction-map-and-aw-fitting-lessons-2026-09-02.md` §"可外推的边界"
✅ 列表："**时间相对量级（Spearman ρ=0.874）**"

**为什么失效**

ρ = 0.874 只在 2026-09-02 可见的版本子集上算得，且是**秩相关**（只说明"更慢的版本
通常更慢"），不能给出 300 s 硬限附近的**绝对位置**。放到 21 个版本上做线性回归，
单变量模型 R² 只有 **0.432**、MAE **18.6 s**——在 300 s 硬限附近，18.6 s 的误差
就是通过与超时的分界。

**取代结论**：见 §3 的分解模型。关键机制差异：

| 本地 1 秒 | 官方等值 |
|---|---:|
| Linear 校准（W_calib） | **0.115 s**（GPU 大矩阵，鲲鹏相对便宜） |
| Attention 校准（A_calib） | **0.694 s**（小张量 + 控制流，鲲鹏贵 6 倍） |
| 动态 activation | 0.734 s |
| 动态 Q/K/V | −1.584 s（负系数，为共线伪影，不解读为"加速"） |

## 5. "不存在统一换算比例 / 不换算官方时间" —— **部分失效**

**原始位置**

- `docs/evaluation-attribution-2026-09-01.md` 结论 3："v86 本地 API 约 299s 而官方
  222.7s…**说明不存在统一换算比例**"
- `logs/execution/2026-09-02-reeval5-10versions-default-trend.md`："本地秒数只做同机
  诊断，**不换算官方时间**"

**如何修订**

**分数部分仍然成立，且被强化**：不是"不存在统一换算比例"，而是**根本不可换算**——
逐 case 特征 + LOO 的 MAE ≈ **1108 分**，而当前有意义的单步官方增益只有 **1~123 分**，

**结论从"谨慎换算"升级为"禁止换算"。**

**时间部分失效**：现在有可用的换算（§3）。

**执行含义**：以后写"不换算"时必须区分**分数**（绝对禁止）与**时间**（有模型，
判据 < 280 s）。

## 6. "官方时间含 ~140 s 评测器开销" —— **被取代**

**原始位置**

**为什么失效**

**取代结论**：用 §3 公式；不要把官方时间拆成"固定开销 + 本地时间"。

## 9. 本地量化拟合的两条修订

### 9.1 "本地 mean 微调不迁移官方（ρ = 0.224）" —— 结论升级

**原始位置**：
`docs/superpowers/archive/plans/2026-09-02-linear-attention-dual-track-generalization-plan-completed.md`
（`MEMORY.md` 同条目已于 2026-09-04 更新）

ρ = 0.224 只说明"弱正相关"，容易被读成"调大本地 mean 大概率也涨官方分"。
2026-09-04 的 LOO 定量检验表明：

- 最优逐 case 特征组合（Δmean + Δtail）MAE ≈ **1108 分**；
- 当前有意义的单步官方增益只有 **1~123 分**；
- **L1 与官方 Δ 负相关（ρ = −0.469）**：本地改得越狠，官方越可能负。

**取代结论**：不是"弱迁移"，而是**本地数值对官方绝对分不携带可用信息**。
本地只做**符号/风险判读**。

### 9.2 真正可用的两条本地判读

**(a) R2 门禁**：`Δmean > 0 且 L1 < 0.02`（L1 = 逐 case gain 的平均绝对变化）

- 在 17 个官方已回传的侧隔离配对上 **5/5 零误提交**；
- 正确拦下历史上三次最大官方损失：**−1163 / −1164 / −165**；
- 分段证据：微扰区间（L1 < 0.02）Δmean 符号一致 7/9；大改区间 4/8
  → **大改即使本地正向也基本是掷硬币**。

**(b) 机制类型（二元特征，比任何连续统计量都强）**

| 机制类型 | 官方非负比例 | 实例 |
|---|---:|---|
| **解析 / 结构等价变换** | **6/6** | v158A / v168A / v166L / v180A / v182L / v183A |
| 校准统计拟合 | **1/5**（最好 +19） | v138–v147 的 A@W 族 |

**执行含义**：新机制**优先选解析型**；校准统计拟合类（在标定数据上最小化某目标）
默认视为本地分布过拟合，除非有强解析理由。

## 10. Attention : Linear ≈ 3.61 : 1 —— **改口径保留**

**原始位置**

- `AGENTS.md`："当前已实现边际为 Linear `3586`、Attention `12944`，约 `1:3.61`"
- `docs/current-solution-status.md`（两处："3.6 倍" / "3.61 倍"）
- `docs/superpowers/plans/README.md`
- `solutions/20260903_v164_*/result.md`

**如何修订**

**结论：`3.61` 仍然正确，不需要改。** 需要改的是 2026-09-04 分析文档初版自己犯的一个
算术错误——它把"侧隔离提交总分 `S`"当成侧贡献 `C` 代入比值，得出 `14008/4590 = 3.05`。

`4590 = S(v166)`、`14005 = S(v168)` **都含 1001 零点**，必须用 `C = S − 1001` 折算：

| 口径 | 计算 | 比值 |
|---|---|---:|
| v160（旧，AGENTS.md 在用） | `C_A/C_L = 12944 / 3586` | **3.61** |
| v182（当前） | `C_A/C_L = 13007 / 3590` | **3.62** |
| ~~分析文档初版~~ | ~~`14008 / 4590`~~ | ~~3.05~~ ❌ 零点未扣除 |

两个正确口径一致，**"Attention 边际 ≈ Linear 的 3.6 倍"这个判断稳固**。
分析文档 §3.2 已就地勘误，差距分解表改为 `C_L: 3590 → 4491（+901）`、
`C_A: 13007 → 16273（+3266）`，相对提升 +25.1%。

**必须同时保留的限定**（`AGENTS.md` 原有，重申）：该比值**混合了官方权重与当前算法
质量**，只指导优先级，**禁止作为本地 gain 到官方分的换算率**。

**用于 4167 分差距分解**（v182 → 榜首 21765，放大系数 `20764/16597 = 1.2509`）：

| 侧 | 当前 C | 目标 C | 缺口 | 相对提升 |
|---|---:|---:|---:|---:|
| Linear | 3590 | 4491 | +901 | +25.1% |
| Attention | 13007 | 16273 | +3266 | +25.1% |

本地剩余 headroom（L 0.363 / A 0.258）在**数量级上够**，缺的是机制不是 headroom。

## 13. 让本地真正"能拟合"的唯一路径：OOD 测试集

以上所有失效项的**共同根因**只有一个：本地校准语料与测试语料**同源于 WikiText-2**。
这使得"拟合本地窗口统计量"在本地不可检出——v140 / v155 / v156 的
"本地 +0.06、官方 −1163" 正是如此。

**方案**：新增**离线 OOD 语料**（与 WikiText-2 不同分布），用
`gain_in − gain_ood` 作过拟合指标。

- 无需官方提交；
- 需要：新增离线语料 + 评测器改动（OOD case 生成与 paired 统计）；
- 这是**唯一**能让本地数值重新携带官方信息的改动，其余任何"更好的估计量"
  （Δtail / 分位 / 加权 / 分 role）在现有数据上已被 LOO 证否。
