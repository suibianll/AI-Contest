# HiF4 历史归档算法总结（v000–v104）

> 整理日期：2026-08-30
> 范围：`solutions/` 下全部归档候选（当前至 v104）与外部参考，按**算法族**归纳，不按版本号罗列。
> 逐条清单与未实现方向见 [`算法全景`](algorithm-inventory-and-directions.md)。
> 口径：本地只比 Qwen 同口径 panel（`250·g_L + 200·g_A`）；官方为 250 Linear + 200 Attention case，上限 420s。

---

## 0. 一句话总览

当前已归档至 **v104**，可归纳为 **9 个算法族**。当前根（clean + B1 GQRB + B2 PAWV diag-only，panel `293.797`）是历次改进的累积结果。

2026-08-30 增量归档：v098 B1 GQRB margin 将 panel 提升到 `293.793700`；v099
PAWV rank-8 跨 token 变体在 layer-1 回退；v100 PAWV diag-only 提升到
`293.797301`；v101 C0 五模型确认通过（Qwen API `401.131s`）；v102/v103 GALS-C
解析候选虽召回 oracle `1.0`，两个稀疏部署均在 layer-1 回退并归档；v104 A7
量化后权重 Gram 在 layer-1 正向但全层回退并超时。当前根源码规范 LF SHA 为
`617482cee04ff9514a8d41226b651336e4b8b86692673308e835de1091693eba`。

**三条最重要的历史规律**：

1. **最大跃迁来自工程重构，不是单一新算法**——从 C86 实验集合重写为 clean 单一路径，再叠加 B1/B2，当前提升为 **+9.91%**（267.308 → 293.797），超过任何单个机制。
2. **跨模型不一致是头号杀手**——v044（OPT −826）、v071（OPT −139，同时 GPT-2 +8.3、Qwen +30.7）、v061（Qwen −20.2）都是"单模型大幅正向、另一模型灾难回退"。
3. **凡是把校准信号用得更"狠"的方向，几乎都过拟合**——全宽 A@W、逐块 A@W、大步长网格、高混合比例，全部失败；稳定配方是"多折 + 尺寸上限 + 自适应 headroom"。

## 1. 激活侧量化族（贡献当前根的核心能力）

| 算法 | 代表版本 | 要点 | 结论 |
|---|---|---|---|
| Wide activation quadratic | v013–v017 | 宽激活二次型，按 Gram 选量化参数 | **采纳**，v013 官方 15799（旧口径） |
| Gated activation | v017、v019、v020 | 门控 + coverage 4%/8% | **采纳**，逐级 +0.0015~+0.0029 |
| Cross-term / cross-aware gain | v021、v022 | 激活/权重误差交叉项 | 采纳，小幅正向 |
| 动态激活损失覆盖目标 | v066 / C66 | 覆盖目标设为 1.0 | **采纳，官方 22557**（本地归档冠军） |
| Gram-8 / gram64 激活精修 | v069、v076、v080、v084 | 从静态变换后权重计算 64 维 Gram block，按二次型选层级与 E6M2 offset，再做坐标扫描 | **当前根核心**，coverage 与 sweep 数逐级正向（+1.22 / +5.31 / +1.92） |
| 量化后权重 Gram 激活 Hessian | v104 / A7 | 用部署近似权重 `WqᵀWq` 替代浮点 `WᵀW` | **拒绝**：layer-1 panel `336.562922`，full panel `290.226694`，API `470.58s` |

**规律**：激活侧的收益来自"用更准的二阶信息（Gram）指导层级与 offset 选择"，且**覆盖率与扫描轮数单调递增有效**（50%→100%、2 轮→5 轮都是正向）。这一族是当前根 panel 的主要来源。

## 2. 权重量化族

| 算法 | 代表版本 | 要点 | 结论 |
|---|---|---|---|
| Top-K 二次型（8/16/32/64） | v006–v011 | 按块重要性选 Top-K 做二次型优化 | 逐级小幅正向（+0.0006~+0.0110），边际递减明显 |
| FULL64 | v027、v031 | 完整 64 维块求解 | v027 当时拒绝，**v031/C39-FW 官方 21864**（机制后被推广） |
| Weight headroom | v054–v056、v058 | 权重 headroom 覆盖 50%/75%/100% | **采纳**（+4.73 / +1.82 / +0.59）；offset ±6（v058）无效 |
| `weight_sample` 候选规模 | v063、v064、v067 | Linear 候选采样 512/640/1024 行 | **512 行最优**（v063，五模型 +17.84）；1024/640 均回退 |
| cross-fold Weight-HSDQ | 当前根 | fold 1 生成的候选必须改善 fold 2 | **采纳**（当前根组件） |

**规律**：权重量化的边际收益随"块更大/覆盖更多"而递减，512 行采样是精度与过拟合的平衡点。

## 3. 等价坐标变换族（风险最高、争议最大）

| 算法 | 代表版本 | 要点 | 结论 |
|---|---|---|---|
| R64 incoherence transform | v026 / C22 | 随机 64 维旋转提升不相干性 | **拒绝**（所有分量回退） |
| CAT（Concentration-Alignment） | v036、v037、v038、v044、v046、v049、v050、v051、v052、v061、v062 | 用激活/权重二阶矩的矩阵几何平均对齐主方向 | **部分采纳**：β=0.25（v037）+ 宽度分流（v062）+ 通道分组（v050/v051，官方 22451）有效；β 网格（v044，OPT −826）、full-H selector（v038）、block-Hessian 度量（v049）、窄 β 细化（v046）全部失败 |
| CAT + micro-Hadamard | v053 | 16/32 通道微 Hadamard | 拒绝（持平，未接受任何组合） |
| BOAT / BOAT-2 | 当前根、v090、v093 | 对角 alpha + signed-Hadamard；BOAT-2 增加 blockwise balance、层级感知置换、Householder | **当前根的 BOAT 有效**；BOAT-2 的两个变体**全部失败**（v090 −0.777、v093 −10.595 且超时） |
| GQA head-local rotation | v075 / C76.4 | GQA 结构下的 head-local signed Hadamard H16/H32/H64 | **采纳**，Qwen Attention 63.12 → 70.96（本轮最大 Attention 增量） |

**规律**：变换族是**双刃剑**——同等变换（BOAT、GQA rotation）安全有效；引入额外自由度的变换（R64、BOAT-2、CAT 的复杂变体）极易在异构模型上崩溃。判决标准是"能否被所有模型一致接受"，而非单模型增益。

## 4. 输出目标 / 联合重构族（合规边界内）

| 算法 | 代表版本 | 要点 | 结论 |
|---|---|---|---|
| Exact discrete cross-gain | v023、v024 | 用输出信息选激活量化 | **不合规**（输出监督喂给 Q(A)），官方 16043/16081 仅作历史记录 |
| A@W 静态 Q(W) 产品选择 | v039–v048、v057、v060、v065、v068 | 冻结 Q(A) 后用 A@W 优化离线 Q(W) | **部分采纳**：多折 + max-dim 4096（v042 +5.19）、自适应 headroom（v043 +15.89）、输出行数限制（v048 +0.09）有效；比例 25%（v057）、步长网格（v060）、软混合 0.50（v065）、预算 15%（v068）、固定 Q(A) 产品目标（v039）、全宽 8192（v047）**全部过拟合失败** |
| 逐块 A@W headroom 混合 | v059 | 每个 64-block 独立混合 | **拒绝**（OPT −14.67，最严重的过拟合案例之一） |
| JDRQ（层级残差） | v072、v073、v074 | fixed-Q(A) 下的层级残差重构 | **采纳**，Qwen +6.45，且**未出现 C71 式崩溃**（v074 的 H32/H64 output reranker 因合规审计禁用） |
| 外部 v2.6 X/W 联合残差补偿 | v070 / C70 | 移植外部核心机制，3 轮 Gauss–Seidel | **拒绝**：GPT-2 +6.27，但 OPT −0.62、Qwen −6.99 |
| proj H32/H64 终量化器排序 | v071 | 输出重排序 | **拒绝**：GPT-2 +8.33、Qwen +30.74，但 OPT **−139.32** |

**规律**：这是收益与风险都最高的一族。有效配方必须同时具备**多折验证 + 尺寸上限 + 低自由度**；任何"全宽/逐块/大网格"的扩展都会过拟合。**外部 v2.6 的核心机制在本工程上未能复现收益**（C70），说明差异在实现细节而非机制名。

## 5. Attention 专项族

| 算法 | 代表版本 | 要点 | 结论 |
|---|---|---|---|
| A1 真实 Attention 输出选择器 | v003 / C1 | 用真实 Attention 输出误差选候选 | **采纳**，Attention 0.3786 → 0.4497（历史性跃迁） |
| 段 CVaR | v004、v005 | 独立段 / query 段 CVaR | 拒绝（causal 回退） |
| K-centering / scale-aware K center | v033、v034 | `K−1cᵀ` 是精确 softmax 不变量，中心由不动点迭代求解 | **v033 全模型启用失败**（GQA −0.88%）；**v034 仅 MHA 启用成功**（五模型无一负向，官方 21864） |
| Q/K 共享 block-Hadamard | v086 / C86 | 4/8/16 维共享 Hadamard + 终选器 | **采纳**，GPT-2 Attention 明显提升，OPT 小幅回退 |

**规律**：Attention 的两条安全路线是**精确不变量**（K 平移、Q/K 平衡）与**共享结构化旋转**。GQA 与 MHA 必须分开处理——这是 v033→v034 的核心教训。

**现状**：Attention mean `0.842039`，贡献 panel `168.408`（已超过 Linear 的 `125.389`）。

## 6. 误差反馈 / 二阶方法族（几乎全军覆没）

| 算法 | 代表版本 | 要点 | 结论 |
|---|---|---|---|
| Robust Block-LDLQ 128 | v032 / C40 | 跨块 LDLQ 误差反馈 | **失败**：本地 +0.36pp，官方 −181 分（本地/官方反向的经典案例） |
| MR-GPTQ | v041 / C44 | full-H 覆盖 97% | 拒绝（−4.72，扩大 coverage 扩散误差） |
| 跨 block LRH（rank-8） | v092、v095 | 真正的跨 64-block 低秩 Hessian，含激活侧全局版 | **全部失败**（v092 −1.328、v095 −11.138） |

**规律**：本族在本赛题上**连续三次失败**（C40、v092、v095）。可能原因：评测器提供的是真实未量化激活，跨块二阶结构在校准集上估计不准，迁移到 test 就反向。建议在投入前先用单层异构模型（尤其 OPT）复筛。

| 算法 | 代表版本 | 要点 | 结论 |
|---|---|---|---|
| activation scale-code oracle | v028 | 激活尺度码 oracle | 仅诊断，无提交源 |

## 9. 成败判据（从 96 个版本提炼）

### 成功的算法共同具备

1. **低自由度**：β 固定 0.25 优于 β 网格；512 行采样优于 1024 行；共享 Hadamard 优于 per-block。
2. **多折验证**：fold A 生成、fold B 必须同步改善（JDRQ、A@W 稳定配方都是多折）。
3. **尺寸/覆盖上限**：max-dim 4096、输出行数限制、coverage 上限 12%。
4. **结构门控**：按 MHA/GQA 分开处理（v034）、按宽度分流（v062）。

### 失败的算法共同具备

1. **单模型正向即推进**：v071（Qwen +30.7 但 OPT −139）、v044（OPT −826）是典型。
2. **自由度过高**：步长网格、逐块混合、全宽预算、β 网格。
3. **把校准信号用满**：全宽 A@W、8192 预算、3 轮 GS 联合补偿。
4. **二阶结构跨块外推**：C40、v092、v095。

### 数字基准

- 单点噪声水平：**< 0.1%**（E0-G 实测）。任何小于此的"改善"都不可信。
- 九连败（v087–v095）幅度：−0.5 ~ −11.1，全部远超噪声 → 系统性失败，非偶然。
- D0 三层 oracle 显示局部 activation-Gram gap 可达 `6.652%`，但没有跨模型/跨层稳定性，不能直接换算成部署收益。
- 时间：当前根 v100 six-API `392.42s` / wall `424.69s`；C0 Qwen 复测 API `401.13s`，仍低于 420s。
