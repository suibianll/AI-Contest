## 0. 结论摘要

1. 现役范式内每根轴（连续坐标、scale/lv 求解器、码分配、rank 残差、coverage、V 侧、
   动态 per-call）都已被三层独立诊断或官方负回传钉死为饱和；最近五次官方提交全部落在
   ±4 噪声带。栈内调参已无可回收收益。
2. 差距分解：4166 分 = Linear +901 + Attention +3266（78% 在 Attention，且官方增益
   85% 在 Q/K 路径）。
3. **格式不背锅**：以 P2 的 R1（mantissa 连续化）为条件的格式天花板（本地 gain 口径
   L≈0.88 / A≈0.95）高于榜首的朴素本地换算目标（L 0.796 / A 0.929）——21765 在 HiF4
   五字段内理论可达，缺口是"与网格共存的算法代际"，不是格式表达力。
4. **现役算法范式不够**：完美收回全部非网格残差（Q/K 18%、W 23%、X 49%）也只到
   L≈0.75 / A≈0.79，够不到目标。
5. 直接攻击网格噪声主项（Q/K 误差的 82%、W 的 77%）的合法杠杆现有**两条并行线**：
   ① **NVFP4 离散码本精确转换**——输入不是连续值而是 E2M1 码 × E4M3 子块 scale 的离散
   码本，7 个非零 E2M1 码全部落在 HiF4 可表示值集内；选对 E6M2 sf 可使对齐子块**精确
   落位、零量化误差**。此线已由《NVFP4 Codebook 精确转换计划》登记为活动计划（P0 在途，
   G0–G3 门槛预注册）。② **层级子组分区 × 离群隔离目标**——R3 只测了 lv 的**值**粒度
   （固定分区、连续化无余量），**分组**粒度从未被任何诊断或搜索以该目标探测过（P2 §5.3
   指认的"更细的块内结构"）；最接近先例 C30（Hessian 边际效用分层分组）实数据评测被拒
   且默认关闭。
6. 建议顺序：活动计划 P0（码本精确占比实测）优先在途，按其预注册门槛裁决；本文诊断包
   （激活侧 S1 解剖 + 层级分区 oracle）与之正交、不共享产物，宜在其 G0 裁决前后择机
   执行；同时登记"平信号解析候选官方直测"政策（A1 先例）；全部归零则转入"与网格共存
   的联合优化"系统研究。

## 1. 实验记录中的规律（按证据强度排序）

### 1.1 官方边际收益三数量级衰减，栈内调参已死

官方 step_gain 序列（全部有归档回传）：

```
v159 +671（GPTQ 栈重写）→ v158 +117（解析 Attention）→ v175 +62（组合）
→ v168/A1 +60 → v180/D1 +3 → v166/rank1 +3 → v182/rank2 +1 → v186/窗口+4 +1
→ v183/coverage 0 → v188/Jacobian 移植 −4
```

最近五次全部落在 ±4 整数化噪声带内。历史上仅有的两次大跳变都是**机制代际更替**
（解析 Attention、GPTQ 栈替换），不是参数调优。与 S1 解剖"现役范式内无可编译目标"
的结论互证。

### 1.2 机制类型是最强的官方预测因子（强于任何本地数值）

[拟合分析 §2.4](official-local-fitting-analysis-2026-09-04.md) 的二元标签：

| 机制类型 | 官方记录 |
|---|---|
| 解析/结构等价 | **6/6 非负**（+117、+60、+3、+3、+1、0） |
| 校准统计拟合 | 家族口径 **1/5 正**（最好仅 +19），其余 −79/−165/−288×2/−1163/−1164 |

叠加硬门 `L1 < 0.02`（逐 case gain 平均绝对变化）：L1≥0.02 的四个大改全部官方大负。
两个已记录的边界：① 跨模型探针与官方排序 ρ=−0.071/−0.200，不携带任何官方信息；
② v188 证明门禁有"近零盲区"——Δmean≈+0.0004 通过门禁但官方 −4，近零信号的官方
期望值就是噪声。反向边界同样重要：**A1 本地 Δmean=−0.00088（负）、官方 +60**——
门禁对解析型强先验候选存在系统性假阴性（见 §4.3）。

### 1.3 误差结构三层闭环：现役范式的合法自由度全部饱和

2026-09-05 两份归档计划用三层独立诊断钉死：

### 1.5 可加性三重成立 + 时间经济学

- **可加性**：侧间 interaction=0（v175 精确验证）、QK/V 可加（−38）、形状桶可加（残差
  +1）→ **侧隔离提交的信息效率最高**，组合提交只给 ΔC_L+ΔC_A。
- **时间**：`T ≈ 170.3 + 0.115·W_calib + 0.694·A_calib + 0.734·dyn_act − 1.58·dyn_qkv`
  （R²=0.799/MAE 10.1s，判据 `T_pred<280s`）。**权重校准在官方机便宜 6 倍**（0.115×），
  Attention 校准/动态贵（0.694/0.734×）。历史全部超时（v128-131/v161/v184）都在
  Attention 侧动态/校准复杂度。榜首 290s 比 v186 多 18s 官方时间——若花在 W_calib
  上相当于本地 ~156s 额外权重校准，与"榜首做更重校准"的推测一致。
- **工程先例**：v184 双窗校准门控超时的根因是双窗架构本身（×2 校准），单窗 +4 变体
  （=v186）以近零校准成本拿到同机制收益 → **新机制的逐层门控应使用单窗 deployed-MSE
  门**（block-smooth 同模式，官方 12944 已验证的机制类）。

### 1.6 过程性规律（方法论）

- "饱和"判定几乎都是**条件性**的：单臂放松（R1/R2/R3 固定其余字段）、固定管线的
  穷举（diag-1 给定码分配规则）。v186 的 +4 窗口是"条件切片漏掉联合缺口"的实证：
  校准侧宽搜索 0 收益、在线侧 +4 独得全部 → **联合空间与条件空间可以不一致**。
- 官方负回传后不扫邻域、每机制一个预注册配置、本地只做符号/风险判读——这些纪律在
  17 个官方配对上把最大损失拦在门外，应继续执行；需要修订的只有 §4.3 一条。

### 2.2 三个天花板的换算

用 P2 的 R1 残差与 P1 的分臂误差（均 v186 同坐标口径），把 player 误差换算成三个
口径（假设：P1 的 `mse_to_ref` 与 gain 口径同分布、可线性换算；Attention 本地 gain
取 v186 ≈ 0.752 = 0.7418 + 0.0103，Linear 取 0.6366）：

| 口径 | 定义 | Linear 误差（vs player 3.10e-3） | Attention 误差（vs player 2.74e-3） | 折算本地 gain |
|---|---|---|---|---|
| 现状 | v186 player | 3.10e-3（100%） | 2.74e-3（100%） | L 0.637 / A 0.752 |
| **现役范式天花板** | 完美收回全部**非网格**残差（R1 剩余：Q/K 18%、W 23%、X 49%；V 关闭不计） | 2.10e-3（67.7%） | 2.32e-3（84.7%） | **L≈0.75 / A≈0.79** |
| **条件格式天花板** | R1：mantissa 连续、其余字段维持现状（非法，上界参照） | 1.00e-3（32.4%） | 0.59e-3（21.6%） | **L≈0.88 / A≈0.95** |
| 榜首朴素换算目标 | 拟合分析 §3.2（明示顶端换算不可靠，仅量级参照） | 1.74e-3（56.1%） | 0.79e-3（28.6%） | L 0.796 / A 0.929 |

> 注：真实格式天花板 ≥ 条件格式天花板（分区/尺度联合优化可在 R1 之上再降网格噪声，
> 见 §3.2），因此下述推论 1 是保守的。

### 2.3 三个推论

1. **格式不背锅**：条件格式天花板已高于榜首朴素目标（且真实天花板更高）→ 21765 在
   HiF4 五字段内理论可达。缺口是"与网格共存的算法代际"，不需要突破格式。S1 报告的
   "榜首可能采用更高表达力的非等效合法表示"应精读为**表示用法**而非格式表达力。
2. **现役算法范式不够**：范式天花板（L 0.75 / A 0.79）低于目标 → 即使把全部非网格
   残差收回（而这要求不存在合法杠杆——scale/坐标/码分配均已饱和，clip 方差分量无已知
   合法手段），仍差约 1/3。**必须找到改变"进入编码器的值分布粒度"或等价效果的新机制**。
3. **直接攻击网格噪声主项的合法杠杆有两条，机制互补**：
   - **码本精确转换**（活动计划在途）：网格噪声存在的前提是"值不在格点上"。NVFP4
     输入是离散码本（E2M1 码全数落在 HiF4 可表示值集 S 内，见活动计划 §1 引理），
     选对 sf 可使对齐子块**精确落位、零误差**——本质是在对齐块上直接兑现 R1 天花板
     的对应份额，而非逼近它；可达规模由码本-sf 对齐统计决定（活动计划 P0-F2 正在实测）。
   - **层级分区**（未测）：对不对齐的块，网格噪声 ∝ 有效 scale²，而有效 scale =
     scale_factor × lv2 × lv3，lv2/lv3 的离群隔离能力取决于**哪些元素共用一个 4 元素
     子组**——这由分区决定，而分区在全部历史诊断中固定为连续切分。

## 3. 诊断矩阵的缺口（哪些"饱和"是条件性的）

### 3.1 已覆盖的探针

| 自由度 | 探测方式 | 结论 |
|---|---|---|
| 连续坐标（等价变换） | P1（B≈0）+ Householder/full64/单折邻域官方与本地关闭 | 饱和 |
| scale_factor（E6M2） | diag-1 ±24 码穷举 × 精确层级（Linear +0.000169）；P2 R2 连续化无余量；+4 窗口已被 v186 收走 | 饱和 |
| lv2/lv3 **值** | P2 R3 连续化（固定分区/码）无余量 | 饱和 |
| mantissa 码分配 | 权重 GPTQ（diag-1 联合饱和）；L3 full64 块级精化跨折叠不稳定被拒 | 饱和 |
| rank 残差 | rank-1/+3、rank-2/+1、rank-3 关闭 | 饱和 |
| Attention 乘子结构 | A1（per-KV-head，+60）、D1（非对称折叠，+3）、C2/D2 细粒度（负）、C1/C3（负）、Jacobian 移植（−4） | 低粒度饱和 |

### 3.2 从未探测的维度：层级子组分区 × 离群隔离目标

- HiF4 层级结构（`reference_hif4.py`）：64 块 → 8 组×8 元素（lv2）→ 16 子组×4 元素
  （lv3）；有效 scale = `scale_factor × lv2 × lv3` ∈ {1,2,4}×scale_factor；
  `_solve_standard_hierarchy` 按 8 值组在 8 个合法配置里做 MSE 最优选择。**分组是
  位置固定的连续切分**。
- R3 测的是 lv **值**的粒度（分区固定）；现役栈的置换只有三类：全局通道置换/
  SmoothQuant-CAT 耦合搜索、C30 Hessian 分层分组（**2026-08-28 实数据评测被拒、
  `_HIERARCHY_PERMUTATION=False`**）、GPTQ 块内列序（只改量化顺序、不改存储位置，
  不影响子组归属）。
- **从未有过的目标**：把块内离群元素聚入独立 4 元素子组、用 lv=2×2=4× 承载幅值，使
  其余子组有效 scale 下降（最多 4×）→ 网格噪声按平方下降。这直接攻击占 Q/K 误差
  82%、W 误差 77% 的网格主项，且是 P2 §5.3 亲手指认的方向（"更细的块内结构/更深的
  层级利用"）。
- **与已关闭家族的区分要求**（新机制卡必填）：C30 的目标是 Hessian 边际效用
  `edge(i,j)=|H_A[i,j]|·sqrt(r_i·r_j)`（跨通道耦合，且当时未加 gate、探针还有 frame
  artifact）；v155/L5a 是压力排序低高交错（分布整形，旧栈官方 −163 语境）；Householder
  是连续域等价旋转。**层级离群隔离的目标函数（子组内幅值方差最小化/有效 scale 压缩）
  与三者不同**，但同属"块内重排"大区——注册前必须先做 §4.1 的 oracle 量化，无余量
  即关闭，不进入实现。
- **与活动计划的关系**：《NVFP4 Codebook 精确转换计划》从"值与格点的对齐"侧攻击同一
  网格噪声目标；分区杠杆改的是"元素与子组的归属"，两者正交、产物与门槛互不依赖。若
  两者都触发机制卡，按 §1.5 侧隔离纪律分别单侧归因，不合并提交。

### 3.3 其他诊断空白

- **输入码本离散性（2026-09-05 晚已由活动计划补上）**：P1/P2/S1 全部把编码对象当连续
  值处理；输入实为 E2M1 码 × E4M3 子块 scale 的离散码本（`evaluator/nvfp4_sim.py`），
  7 个非零 E2M1 码全部落在 HiF4 可表示值集内。该结构的可利用规模（精确转换占比上限）
  正由活动计划 P0-F2 实测。本文 §2 的天花板推算在"连续值"假设下成立且作为上界有效；
  离散性只影响"可达比例"，不影响天花板方向。
