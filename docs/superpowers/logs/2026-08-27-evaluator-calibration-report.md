## 结论摘要

1. 本地评测系统作为**排序/方向代理**高度合理：4/4 官方锚点方向一致，
   留出锚点 v000 误差约 1%；
2. **Linear 兑换率稳定且高**：约 297 官方分 / 每 1pp 本地 Linear mean
   （非负约束扫描下稳定在 29.7k–30.2k 系数区间）；
3. **Attention 兑换率弱**：≤ 约 8.6 官方分 / 每 1pp 本地 MHA attention；
   E1 合成矩阵场景分布与官方（若含合成）明显不同；
4. C21 校准预测官方约 **16150**，距 22000 缺口约 **5850** ≈ 需再
   **+19.7pp Linear**（0.593 → ~0.79）——单靠 Attention 到完美也不够。

## 3. 兑换率结论

- **Linear：~297 分 / 1pp**（= 29700/100）。这是全数据集最稳的数。
- **MHA attention：≤ ~8.6 分 / 1pp**（= 862/100）。C1 的本地 MHA
  +7.1pp + 合成 +8.5pp，按拟合官方只值 ≤60 分。
- **E1 合成 → 官方几乎不兑换**：v000→v001 合成 overall +17.5pp，官方
  只涨 ~1000+（主要由 Linear +3.6pp 与 attention 贡献，合成份额接近 0）。
  官方场景混合（模型、层类型、合成配方）未知，**官方合成 ≠ E1 配方**。

## 4. 22000 缺口测算

- C21 预测：`−1848 + 29700×0.5930 + 862×0.4497 ≈ 16150`（较 v013 +353）；
- 缺口：`22000 − 16150 ≈ 5850`。

| 路线 | 需要的本地提升 | 判断 |
|---|---|---|
| 纯 Linear | +19.7pp（0.593→~0.79） | 唯一可行主线 |
| 纯 Attention（MHA 0.4497→1.0） | 即使完美仅 ~474 分 | **不可能单独达标** |
| Attention 拉满 + Linear | Linear 仍需 +17~20pp | Linear 是必经之路 |

历史工作量标定：v001→v002 的 v2.0 机制级重构 = +16.75pp（其中
proj 0.084→0.482 单分量贡献 ~6.6pp，约 40%）；B0→C21 全链 21 个候选
= +2.62pp。**22000 ≈ 再来一次机制级跳变 + 持续磨分量。**

## 5. 战略含义

1. **下一轮候选优先级应以 Linear 最弱分量为杠杆**：fc（0.51）/
   proj（0.54）/ o（0.56），而非继续挤已到 0.65–0.71 的 q/k；
2. E1 合成矩阵的价值定位是**安全轨**（防 variantH 式 0.0000 灾难），
   不是得分杠杆，heavy_tail 债务的 ROI 有限；
3. 每次官方提交都是一个新锚点：C21 提交后应回填本表重估系数，
   尤其是确认 v013→C21 的 +353 预测（Linear 兑换率的又一次独立验证）。

## 6. 局限与盲区

- 22000 外推超出锚点范围约 39%，线性假设可能失效；
- 官方 Attention/合成权重的真实分布未知，若与 GPT-2+E1 显著不同，
  Attention 侧兑换率结论会变；
- 无法排除两种极端：官方存在本地看不见的灾难弱分量（类似 v001 的
  proj 0.084，修复有超额回报），或官方满分量结构上限低于 22000
  （本模型下不可达）——现有锚点无法判别。
