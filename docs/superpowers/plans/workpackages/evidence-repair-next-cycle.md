> READY / R0，2026-09-07。隶属[唯一活动总计划](../2026-09-07-continuous-linear-attention-plan.md)，不是第二份总计划。

## 1. 本轮交付目标

不是立即证明新机制能到榜首，而是交付三项可独立判断的结果：

1. L：一套与实际六 API 对齐的输入/输出证据，以及修正后的 L1 成本与可执行性结论；不能再用简化探针关闭完整方向。
2. A：R2c 训练/部署前向一致性报告，及一个固定配置的部署目标对齐候选。
3. C：L4+R2c 完整组合的正确性和时间证据，通过条件后准备官方验证。

父版本保持总计划指定 SHA：L4（4607/247s）、R2c（14387.8/240s）。L冻结v162 Attention；A冻结v162 Linear和R2c既有V。没有新官方结果就不替换官方父。

## 3. L-R1：真实输入和部署闭环（必须先完成）

输出目录 `workbench/continuous_linear/repair-r1/`；结果独立存入 `artifacts/proxy_v3/continuous/linear/repair-r1/`。先登记父/evaluator/输入cache SHA与固定cases。

固定小面板为层0、11，role为o、fc_up、proj，读取相应协议现有calibration与validation/test案例；不得把训练窗口当holdout。保留所有case身份，不能只报选中的正例。

### 输入

- 通过 evaluator 的 NVFP4 prepared cache 或其 `nvfp4_encode(..., NVFP4_MODE)` 获取相同carrier/scale。禁止 `round(x/scale)` 自制输入。
- 验证carrier、scale、解码dense与同协议evaluator输入逐位一致；验证输入哈希后才校准。

### 输出和坐标

- 调用父实际 `hif4_calibration_and_quantize_weight`，直接解码其返回weight_params；激活必须调用真实 `hif4_dynamic_quantize_activation`，不能使用简化编码器代替。
- 以原NVFP4解码的XW^T为最终reference，核对真实API输出与父相同case的最终MSE。
- 逐步审计smooth、perm、block transform、rank残差的语义。不得预设rank补偿是保持乘积的可逆变换；若存在非等价补偿，单列reference偏差，不能强行构造“连续零误差”。
- 对可逆部分验证连续乘积不变量；对于完整实际输出验证父子恒等路径。冻结侧control照总计划执行。

### 误差归因

只有在连续参照坐标与两侧实际编码对应关系成立时才报告W-only/A-only/interaction。必须从真实API返回值构造四臂；若无法定义同坐标纯量化分量，报告UNIDENTIFIABLE和完整输出误差，不能给伪精确贡献百分比。

验收：同输入、同父源码、同API路径的最终输出与evaluator一致；输出独立JSON、校验脚本、report。未通过时只修实现，不开始FlatQuant训练、不宣布任何机制失败。

## 4. L-R2：修正版L1的正确性与成本判定

在L-R1闭环上修正原固定L1，不新增参数扫描：两个8×8因子、32步Adam、lr=0.01、固定正则与条件数界限保持原卡。

必须修复：

1. 梯度范数是裁剪上限1，范数小于1时不得放大到1。
2. 每fold至多128行、各fold等权；损失按同fold标准HiF4最终输出MSE归一化，不用输出方差替代。
3. 硬前向使用部署对应的权重和激活编码；state依赖图明确。不能以“成本太高”改用简单codec后仍称同一候选。
4. 对矩阵指数及特征值投影做小矩阵梯度检查，覆盖重复特征值、I初始化和边界；STE只检查声明的替代梯度。训练必须在inference_mode上下文下可达。
5. T=I应恢复父路径；不能恢复时先查rank/状态依赖，不能把父和新目标之间的结构差异归为优化收益。

成本只测固定最小面板中代表state的完整一次训练步，先预热并在计时前后CUDA同步，分开列出变换、state重建、硬量化、梯度和矩阵求解耗时。不新增shape扫参，不用随机数据冒充真实状态。

决策：

- 正确性未通过：IMPLEMENTATION_ERROR，继续修复已定位问题。
- 正确性通过但32步全量结构显然昂贵：COST_HOLD，只记录本机成本估计；禁止将非default探针直接代入官方模型。允许停止昂贵的全量实验，不关闭可逆变换数学方向。
- 正确性和成本均可继续：按原固定配置生成真实候选，再进入总计划shards0,2→完整六shard→OOD/control/fresh default。

COST_HOLD后的后继任务为：寻找不改变硬前向语义的缓存、充分统计量复用或批处理；列出哪些量依赖T，禁止复用过期Gram/Hessian。只有具体实现方案成立才运行；若必须改变求解规则，另立单机制卡并重新注册，不能现场减步数或扫rank。

## 5. L-R3：重新做公式级去重（可与A并行）

GPTAQ与旧JDRQ逐项写出：目标、梯度/曲率、更新公式、未量化变量补偿、离散候选集合、更新顺序、Xh/state冻结方式。尤其验证“残差引导逐坐标选择”是否真的等价于论文含逆Hessian与非对称残差项的逐列更新。

给出一个小型确定性矩阵的单步更新对照，使用相同输入和初始权重。若更新不同，只证明“不等价”，不能证明新方法有效；若公式可证明等价或完整覆盖，则维持DUPLICATE_CLOSED。

证实新规则不同后，先解决真实dynamic state依赖图，再注册一个固定候选进入总计划；未完成这些条件不重跑JDRQ。L3合法编码本轮只修订证据边界，不立即注册更大枚举。

## 6. A-R1：优先推进已获官方收益的路径

当前未找到新阶段Attention产物；执行者先搜索已有同SHA产物或另一工作树，若存在则核验并恢复，不能凭目录缺失断言未做过。

随后按[Attention工作包](continuous-attention.md) A0/A1执行：

1. 从R2c提取真实旋转插入点、已有Q/K state、实际V量化路径。
2. 构造训练硬前向与动态API同输入对照；覆盖GQA、变长Lq/Lkv、inference_mode和回退计数。
3. 只修训练/部署目标错位；优化器、采样、gate等配置从R2c源码固定提取，不同时修改K/V支持集。
4. 小面板后完成真实六shard和官方探索所需证据；候选归档同SHA，正收益不能只来自fallback或改V。

A1有有效裁决后才推进A2完整K/V支持集；A3非正交变换保持后继地位。Linear的修复或等待不阻塞Attention研究。
