## 4. L23：直接用实际A@W误差学习可逆对角坐标（先设计后实现）

假设：旧卡固定真实Q(A)，仅把W拟合回原teacher；新卡保持父连续算子，联合改变两个操作数
的量化坐标，以真实输出误差选择变换。这是待验证假设，不是声称外部方案采用该实现。

**变量与不变量**：在已证明可编译的父坐标插入D=diag(exp(s))，
A_D=A_parent D，W_D=W_parent D^{-1}（权重存为输出×输入）；连续乘积保持父值。
s按输入通道共享全部输出，不加layer/role路由，不增加残差秩、不学任意权重修正。
零s必须完整恢复L4，含rank补偿、permutation、Hadamard与真实activation_state；
不能将含rank补偿的父连续乘积误称原始teacher。

**拟合目标**：teacher始终取原NVFP4解码XW_original^T；
J(s)=mean_f(||Y_f−Q_A(A_D,f) Q_W(W_D)^T||_F² / max(||Y_f||_F²,1e-12))
+ 1e-3 mean(s²)。每fold等权，不用holdout分母或测试统计。
硬前向必须经过父实际HiF4五字段编码/解码，Hessian/Gram在最终变换部署坐标重算。
编码如含离散选择，训练可用显式登记的STE近似，硬前向和最终选择不允许连续权重替代。

**固定首卡配置**：零初始化，16步、全calibration folds等权、Adam lr=0.01，
beta=(0.9,0.999)、eps=1e-8，s逐步投影到[-log(2),log(2)]并去均值；
仅最终一步形成一个提案，与零s父比较，不挑最佳checkpoint，不扫描步数/ridge/边界。
数值设置是本轮预注册假设，不是从外部283s反推。

**选择隔离**：训练fold内部固定按token奇偶划分fit/select，两部分均不得来自eval holdout；
fit学习、select按各fold误差差值的median严格负才接受，平局保留父。
validation/test只用于独立报告，不按它们回调参数。若现有API不足以隔离，则记设计阻碍，
不借用test窗口完成选择。

**实施前条件**：证明D能在父真实状态中成对编译、零点逐位回归；
不能满足就关闭本卡插入点并留下证据，不删除父组件凑实现。
训练只在校准，动态API执行固定变换与编码，不带搜索、求逆或候选循环。
先做梯度/真实硬前向/小形状复杂度检查；不恢复旧32次全栈权重训练探针。
如16步方案官方超时，关闭该复杂度实现，不能机械减步重试。

**否定范围**：合法且reachable但4B负向只否定这个预注册变换/目标；
不称“A@W拟合不泛化”。后继只允许根据误差定位注册一个实质不同机制，禁止rank/步数邻域。

## 5. A23：父坐标下量化块scale乘积目标

依据：A22-2源码保留完整R3再学残余矩阵，已有官方+19；其训练loss是Q与K各自
相对父amax的平方和，尚不等于两者对QK误差的联合作用。新卡只改变这个训练目标，
保留父变换表达空间、完整回退、K-center同步编译、既有优化器与32步，不另加训练阶段。

对每个GQA共享KV组g和编码64块b，在父变换后计算校准块幅度：
a_Q,f,g,b = Q在该组全部Q heads/token上的块amax平方的均值；
a_K,f,g,b = K在token上的对应块amax平方均值。
目标为mean_f,g,b[(a_Q(s) a_K(s)) / max(a_Q(0) a_K(0),1e-12)]
+ 1e-3 mean(S²)。使用与真实布局一致的块映射；常量Q×c、K/c不应虚报乘积收益。
该loss是明确的新代理假设，不能用scale变小直接判成功；最终必须看真实QK和QKV输出。

父为A22-2（SHA 4686AD81…C0B7）。新候选以相同基础父流程训练一个残余提案，
替换该训练目标；不是在A22-2最终状态再叠一套32步。输出选择必须包含完整A22-2父
作为固定回退，新增校准成本如实记录；不用旧R3冒充零增量control。
先记录复用与额外训练调用图，不能声称仅改loss就没有额外成本。

保留父fit/select窗口划分并验证不重叠；若审读发现重叠，先独立修复隔离并验证，
不能把隔离修复和loss收益混为同一机制。D或exp(S)的互逆转置关系、GQA组映射、
center变换、零残余与强制回退均做数值检查。V和标准Linear逐位冻结。
记录attempted/accepted/changed，以及Q/K实际解码误差、QK、logits/probability、QKV、
最坏长度/层；这些用于解释，不据测试桶结果增加专属路由。

结果分支：scale乘积下降而输出不改善，只关闭此目标；下一卡才考虑实际量化QK目标，
先与旧Jacobian/动态Gram关闭族去重。不得扫loss权重、窗口或gate阈值。
