## 3. L21-1：固定层级的块内逐列条件求解（唯一立即执行卡）

### 3.1 真实目标和数据

一次取得父activation_state与合法weight_params，解码父权重为W0（部署维度d×o）。
每个calibration fold通过真实dynamic activation得到Xh_f，teacher严格为原NVFP4解码的
`Y_f=X_f W_original^T`。目标为合法W上的

`L(W)=Σ_f ω_f ||Xh_f W−Y_f||²`，`ω_f=1/(F·max(MSE_STD_f,epsilon)·N_f·o)`。

STD误差只用对应校准输入的标准HiF4完整A@W求得，epsilon=1e-12；不能使用验证/测试误差作分母。
这把各fold归一化MSE等权；不取最好fold。校准行数与窗口继承父固定规则，实施前写入config的
实际索引及输入hash；不得沿用被审计否定的简化codec，也不按holdout挑样本。

先验证Xh列维度与W0行维度一致、原始teacher输出形状正确，并核实父state是否绑定权重。
若不能保持state不变而替换weight_params，记录契约阻碍并进入L21-2设计，不能悄悄重建state。

### 3.2 固定合法空间

固定父scale_factor、scale_lv2、scale_lv3，优化sign/mant，合法值为
`scale_factor·scale_lv2·scale_lv3·{−1.75,−1.50,…,0,…,1.75}`。
更新必须写回五字段；不保留连续残差、不提高位宽、不改共享层级、不扫描offset。
“单个mantissa可更新”不代表层级可独立逐元素更换。

### 3.3 可直接实现的条件更新

以下是本卡明确的块条件求解器，不冒充已经复现某篇论文的完整实现。
按父部署列顺序逐个连续64列块B处理，**一遍**，其余列固定为当前合法W。
维护残差 `R_f=Y_f−Xh_f W`。对当前块：

`H_B=Σω_f Xh_B,f^T Xh_B,f`；
`D_B=Σω_f Xh_B,f^T (R_f+Xh_B,f W_B)`。

沿用父在相同块Hessian坐标下的既有ridge标量规则，实施前记录其确切代码/数值；
以块父权重为正则锚：`Hλ=H_B+λI`，`Dλ=D_B+λW_B`，解 `Z=solve(Hλ,Dλ)`。
这只是连续初始化，**不能在这里量化一次就声称完成逐列算法**。

令剩余列逆Hessian为F。固定列i时，按其父合法格点最近舍入并截断得到Qi，
随后对尚未固定的r列执行：

`Z_r ← Z_r − F_ri/F_ii · (Z_i−Qi)`；
`F_rr ← F_rr − F_ri F_ir/F_ii`。

每固定一列，后续连续最优解随该离散约束变化；已经固定的Qi不再改。
输出通道并行，块内列顺序固定；实现可用等价Cholesky条件更新避免数值消减，
必须与小矩阵直接条件重求解逐步一致。奇异或非有限块保留父，计数且报告，禁止扫ridge修补。

获得块合法提案后，用真实校准目标L比较“当前块/提案块”，严格改善才替换，平局保留当前块；
更新 `R_f ← R_f−Xh_B,f·ΔW_B`。这只是训练目标上的固定两臂选择，不使用holdout选择。
块内精确条件补偿不等于全d维全局最优：跨块通过残差更新、一遍块坐标处理，边界须如实记录。

区别于旧JDRQ：旧局部码±一格残差下降不自动包含“固定一列后对所有剩余连续列的条件最优补偿”；
需用小例子的中间Z、Qi、F和最终合法码证明区别，不能仅比较损失表达式或岭解。

### 3.4 固定成本设计

只校准一次state、编码一次Xh；H_B每块累计一次，不每列重新量化激活或构造全量输出。
64为实际codec块，不扫块大小；输出通道可固定128列分片降低残差内存，分片只能改变调度，
数学结果需与未分片小例子一致。行采样不因成本失败临时缩小，不能把分片时间外推官方。
动态activation保持父；权重量化规则和所有条件求解仅校准执行。

## 4. 检查、官方探索和失败分支

1. **数学最小检查**：独立直接条件最小二乘参考，非对角H、非对称teacher、零/奇异块；
   检查每列固定值、剩余变量、最终合法码。与旧JDRQ不同只证明新机制，不证明更优。
2. **真实闭环**：复用12/12证据，不重跑整套审计。新增检查只覆盖替换权重后state冻结、
   activation输出逐位不变、合法五字段、finite、attempted/accepted/changed>0。
3. **最小screen**：目标侧smoke及shards0,2；记录零收益是否由于分支未到达、格点未变或被训练gate拒绝。
4. **正式本地验证**：完整六shard336 Linear case，匹配身份、STD MSE和reference energy；
   报mean/median/分位/最坏组/正负case/两split。不能只挑fc/proj role或只看operand MSE。
5. **风险与成本**：负向L1<0.02，总L1只记录；OOD与跨模型仅诊断；标准Attention control；
   fresh default六API预测<280s及单文件检查。已有同口径父结果复用，不重跑父。
6. **官方**：继承原L21-1已登记的一个代表探索规则；本地均值/split负向时如实标EXPLORATORY，
   仍须全部风险/合法/control/非no-op/时间门。未回传不能晋级，不将本地336case换算5000分。

比L4分高且官方<300s才证明首卡有官方收益；分数持平只可能作为实测更低成本候选，
分数退步则不替换父。一次失败不扫描参数，同SHA不重复提交。

| 观测 | 下一步 |
|---|---|
| state绑定/成本使当前设计不能部署 | L21-2精简主干，先验证精简父，再验证输出求解 |
| 条件求解可达、合法码有变化且官方改善 | L21-3登记合法层级联合求解，保留首卡作父 |
| 局部码变化但官方退步 | 关闭此固定层级一遍求解卡；分析固定activation/层级限制，不扫列序/步数 |
| 全部no-op或被gate拒绝 | 查可达与连续目标到格点的变化；不提交，也不宣称合法空间饱和 |
| 本地/官方反转 | 停止proxy排序晋级，后继另登记机制检验规则 |

## 5. L21-2：低成本输出拟合主干（条件卡）

若父过重或state限制使首卡受阻，设计一个一次变换、一次activation编译、一次输出求解的主干。
必须先登记删除/保留组件及成本，不用简化codec冒充L4。
固定两个逻辑对照“精简父”和“精简父+拟合”，分别报告相对L4删除损失与新增拟合收益。
Attention A21-1已证明删旧训练会抵消新收益，Linear不能再将二者混在一个均值里。
首版不同时训练激活变换和离散权重；训练式全栈32次硬前向的旧昂贵结构不恢复。

## 6. L21-3：输出目标驱动的合法层级联合求解（条件卡）

在首卡获得可达且有价值的离散求解或获得外部直接机制证据后，才登记新卡。
依照真实共享64/8/4层级约束，提出固定的联合变量选择/条件补偿规则；先证明与旧合法网格、

也不能由单元素可表示值并集推导最终输出无损上限。
