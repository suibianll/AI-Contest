# A 代理：Attention 持续优化工作包

> READY / A0，主契约：[持续优化总计划](../2026-09-07-continuous-linear-attention-plan.md)。
> 初始父 R2c 14387.8 / 240s，完整 SHA/路径见总计划。两个 Linear API 冻结 v162；V 保持 R2c 原路径。

## A0：建立可验证的部署目标

核对父归档 SHA，建立本侧 state/queue。复用 r2c-id/ood/default 原始结果，但实际读取 manifest 检查身份，不从四舍五入报告构造逐 case 基线。

逐步列出 Q/K 真正执行的中心化、乘子、置换、旋转、编码/解码顺序；记录旋转插入前坐标 U_Q/U_K。特别检查 `_a2_train_rotation` 原始输入与 `_a2_true_path_gate_loss` 真实路径的差异。把训练目标、实际 V 和完整 K/V 的偏差写成矩阵等式，不只写“对齐”。

最小测试覆盖 I/固定父 R、GQA多个Q共享同一KV、Lq<Lkv、inference_mode/no_grad、有限输出、返回state。无 autograd 依赖的手工梯度与小规模可用 autograd/有限差分对照；STE只对其声明的连续替代模型验证，不能声称真实离散梯度正确。

新增训练前向与六 API 部署解码输出逐位一致或报告可解释浮点差异；在该检查通过前，不运行优化器实验。

## A1：真实部署路径内的旋转学习（首个候选）

假设：R2c 的收益受训练/部署坐标与编码器错位限制；修正后应改善实际 Attention 输出。

唯一机制变化：训练硬前向改用旋转插入点的真实坐标，以及父的实际编码规则和量化 V。Q/K所有既有状态固定，不同时修改 importance、offset、gate 或 V。

配置完全继承 R2c 的步数、学习率、初始化、正则、样本索引、训练/gate划分；实现前从源码提取到 config.json，禁止凭旧任务书猜测值。保留手工梯度，硬前向走完整 HiF4 五字段，近似梯度显式记录。

目标：校准窗口等权、按各窗口标准 HiF4 最终输出误差归一化的真实 Attention readout 损失。若父已有归一化/聚合，A1保持原定义；不借修复顺便更换统计口径。父、候选、参考使用完全相同 mask、温度、GQA映射与token集合。

对照只需冻结父与候选；额外 I 用于不变量/实现诊断，不增加算法候选。报告部署目标改变量、训练/gate/holdout一致性及 accepted layers；不能只报训练loss下降。

A1结束按总计划归档并进入下一张卡。若需梯度模型修复，必须证明错误点，保留旧无效 SHA；不同初始化/学习率不算修复。

## A2：训练时恢复完整 K/V 支持集

假设：仅用至多128个K/V训练改变softmax分母和竞争关系，即使校准gate恢复全长也不能纠正优化目标。

前置：审查 A1 实现确实仍截取K/V；若已经全长，本卡标 DUPLICATE 并跳过。

固定配置：保持父 Q 抽样、步数、优化器和所有编码规则；每个训练窗口使用全部K/V，Q按至多32行分块，reference/player用完全相同支持集。手工反传通过分块累积得到该目标的梯度，不在线引入QK计算；所有复杂操作仅校准。

先记录一层每步时间和峰值内存，评估全校准规模；fresh default才提供正式时间预测。不能为挽救超时现场改成256/512 K窗口扫描。若成本不可行，记 TIME_HOLD，转下一机制或单独提出数学等价流式实现。

## A3：受约束的非正交 Q/K 变换

论文依据：[FlatQuant](https://arxiv.org/abs/2410.09426)，仅借鉴可逆变换思想，不继承论文端到端效果或时间。

先与已有 QK balance、pair-transform、Householder 关闭族逐项去重。新自由度必须是已部署坐标中的一般对称跨通道伸缩，不能退化为旧通道倍率扫描。

固定原型：在本轮官方父旋转输出后使用 `T=exp(S)`，每KV组一个对称零迹S，初始0；对称矩阵特征值投影至[-log(2)/2,+log(2)/2]，因此cond(T)<=2。Q乘T，K乘T^-T；校准预计算T和逆，动态仅乘已编译矩阵。采用父优化器预算，新增固定 `1e-3*mean(S^2)` 正则，不扫界限/正则。

原型是有限候选假设，不保证最优。投影/eigendecomposition仅在校准，手工梯度实现需明确矩阵指数导数，不用逐元素exp冒充矩阵指数；若训练实现与时间代价不能落实，先交数学/成本否定，不运行非法近似。

必须证明连续QK保持、GQA一致和冻V，真实编码重新计算依赖坐标的统计量。若同时需要重编译importance，其规则提前登记为该坐标变换必要部分，不能holdout择优。

## 持续后继与停止边界

A1/A2/A3 是初始队列，不是收益承诺。每轮按总计划补队列；优先从实际残余误差提出新的低自由度目标或可编译结构。禁止仅将BoA Hessian对角线换名后重开已关闭Jacobian importance邻域，也不新增动态Gram、V旁路或token专属表。

有时间压力可研究将相邻固定线性变换融合，先证明中心化/缩放顺序一致和输出等价；不能借此重复官方提交逐位等价包。需要算法变化的低秩/结构近似另立机制卡，不把增加rank当连续扫描。

每轮交接写：当前官方父、候选/待回传SHA、实际新增收益、尚存目标错位、下一张机制卡、GPU/官方依赖。仅本地负向不证明Attention达到天花板。
