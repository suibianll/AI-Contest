### 构建顺序

1. 校准基础栈只计算一次，得到B；使用R3原始训练和选择逻辑得到完整父P。
   可提取内部收尾函数复用B，但不得改变旧训练窗口、采样、center、量化或选择规则。
2. 使用**B坐标**执行A21-1原训练函数，得到相同TQ/TK的提案C。
   R0仍为固定Hadamard或I，S=0；32步、lr0.01、clip1、正则0.001、cond≤2、
   epsilon与amax并列梯度全部不变。此卡不在P坐标重训练，不引入新loss。
3. 取消A21-1“C与B比较”的最终gate，改为在原最后校准窗口比较**C与P**真实readout MSE。
   整层选择，严格小于才接受，平局或候选不合法保留P；正常实现错误记录ERROR并修复，
   不用吞异常制造全部回退的假成功。独立holdout不参与选择。
4. 未接受层必须返回完整P的Q/K/V编码行为，包括learned_rotation和learned_center；
   不能只保留基础multiplier/pair transform。不得按已知层号/长度/模型建立白名单。

本轮明确允许校准执行一次旧R3训练和一次scale训练，这是为验证回退假设支付的成本，
**不再称低成本替换**。基础栈、V编码、teacher/gate输入能共享则共享；动态无新增候选循环。
不同时执行A2全长反传，不用缓存state绕过正式校准计时。

  提取共享校准代码后先通过这一检查，再看新算法收益。
- 原A21-1提案函数输入/配置不变，同输入生成TQ/TK一致；不能将更换初始坐标藏在gate修复中。
- 检验B→C连续QK不变、独立GQA映射、真实编码坐标、inference模式可达；复用已验证数学测试。
- 记录层级attempted、accepted、实际回退父身份，所有层P/C的校准MSE与独立holdout误差。

## 4. A22-2：父坐标上的增量互逆变换（依赖A22-1结果）

若A22-1有增益但有限，或多数提案仍被完整P拒绝，下一卡研究“保留P，仅学习残余S”。
先登记独立固定配置；不能直接把该内容塞入A22-1。

设P最终编码前坐标 `ZQ=UQ Rq`、`ZK=UK Rk+c`，缺失旋转视为I、缺失center为0。
训练 `Qnew=ZQ exp(S)`、`Knew=ZK exp(-S)`，S=0必须逐位恢复P。
部署编译 `Rq_new=Rq exp(S)`、`Rk_new=Rk exp(-S)`，
**`c_new=c exp(-S)`**。遗漏center同步变换会破坏父连续QK，必须独立检查。
父存在其他编码前变换时先确认插入点，不以数学缩写代替真实调用链。

先固定与A21-1相同scale目标/预算，分母改为该卡S=0的完整父坐标，
不同时引入敏感度加权或新量化器；与A22-1相比这是新的残余参数化与初始化。
gate仍对完整P。若需要减少成本，另行设计共享统计/矩阵计算，不能静默减少训练预算重试。
官方探索与否在该卡登记时明确，不能自动借用A22-1规则。
