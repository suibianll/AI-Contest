## 2. L-QF1：修正局部二次代价（首卡）

假设：当前候选排序使用了错误的局部二次代价，正确二次型能减少误提议与漏选；是否最终增益必须实测。

- 入口：`_em1_dynamic_descent` 的 `quadratic` 计算；当前式 `krba,bij,krbj->krb`。
- 唯一改动：改为 `krbi,bij,krbj->krb`，实现 `delta^T local_gram delta`。暂不改成特化对角公式、不换计算库、不改其他路径。
- 固定：继承父K（当前1）、8个pm1候选、16组调度、覆盖范围、scale/hierarchy/sign语义及整行联合接受全部不动。
- 工作目录：`workbench/full_solution/linear-qf1-quadratic-cost/`，完整候选自包含；根和既有归档只读。
- 最小验证：非对角SPD矩阵与单坐标/一般delta的显式二次型对照；验证线性项+二次项与直接目标差一致；包含旧式不等于真值的反例。用独立参考式，不写自我重复测试。
- 验证六API独立导入、合法state、finite、Attention/Weight控制、真实提议及最终接受计数、硬码变化；关闭修正时复现父。
- 运行目标侧shard0后六shard一次，记录真实输出差与288/0/48旧证据的同口径对比；不以本地均值正负作官方提交门。
- 若最终完全恢复父/逐位相同，NO_EFFECT，不分配正式版本；若合法可达且非等价，归档单一代表交官方。
- 官方下降/超时只关闭此修正代表，不反复改候选数/阈值/组粒度。官方晋级前，v230原计分源码不改。

## 3. L-TF1：复用首遍梯度（第二卡）

从届时最高分完整根构建；若QF1待回传则仍以已确认根为父，不把未定价修正混入本卡。

- 唯一机制：复用进入pass循环前已计算并检查过的梯度，首pass不重复计算。K>1时保留之后每pass的重算顺序。
- 当前代码前置与首pass均计算 `(deployed-reference)@metric + reference@h_matrix`；中间仅构造索引/候选常量并clone deployed，未改变值。先静态确认此前提再改。
- 不同时修改求逆、矩阵精度、局部代价或共享助手。保留非有限检查与失败路径行为。
- 工作目录：`workbench/full_solution/linear-tf1-gradient-reuse/`。
- 最小控制：正常与非有限路径对照；父子五字段及输出对照；确认少执行一次梯度表达式。计时使用相同state/device和独立无profiler配对，记录中位/离散程度，不换算官方秒数。
- shard0和目标侧六shard各按指引复用/执行一次。若声称纯时间变化，必须证明硬码与输出等价；若出现硬码差异先查原因，不用`|Δ|≤0.002`一类容差声称等价。

## 4. 后续架构降时：先定位，只注册一个代表

前两卡完成开发后，复用已有证据，只补一个明确问题：父激活GPTQ、新增下降、度量求逆/拷贝各自占多少无profiler调用时间？

不可把整API事件数归因于一个einsum，不把view操作当GPU kernel，不比较CPU缓存和GPU实时返回路径的耗时。检查端到端调用顺序、设备和state内存；计数变化只帮助归因，不要求固定百分比。

按实测主项选一项再写实现细节：

1. 若固定度量求逆/传输为主：研究校准构造或复用精确度量，明确CPU状态字节、设备峰值、序列化和每调用传输；不盲目同时保存多份n²矩阵，不引入近似度量。
2. 若原激活GPTQ逐块solve为主：预计算原始块间补偿系数，动态仅按当前输入产生的块序取用；保留顺序补偿。独立验证浮点重结合与异常路径。
3. 若编码小算子为主：只优化已定位的热点，保持编码目标和候选集合，不减少覆盖、舍入候选或refinement轮数换时间。

此阶段尚无选定算法，不同时实现三条；不以猜测计时开大量探针。完成定位后在本计划替换本节为一张固定卡，不新增第二份活动总计划。
