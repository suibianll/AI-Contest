## 1. 目标、口径与启动条件

用户研究目标：在既有4B Attention完整面板上达到 **overall_mean ≥ 0.80**。沿用eval-v3、同NVFP4 dense输入、同STD、同manifest、同case等权：

`gain_i = 1 - MSE_PLAYER_i / MSE_STD_i`；`overall_mean = mean_i(gain_i)`。

0.80表示逐case相对STD的MSE比值均值不超过0.20，不是准确率、不是全部case均≥0.80，也不是汇总MSE下降80%。禁止改分母、重加权、删负case、只报fit或接受层来达标。正式诊断必须完整72例/六shard，并分别列fit/selection/独立validation及层、长度分布；按实际manifest记录，不重定义数据划分。当前同口径均值在启动时从已完成报告提取，本文不猜测；记录到0.80所需的本地实际增量。

## 2. 研究策略

当前根用于回退和完整对照，不要求新精度机制复现旧训练轨迹。纯降时仍须满足其等价边界；本计划研究的是新的合法量化求解方法，必须允许硬码和最终输出发生变化。不得把未获官方验证、纯降时不等价或单个优化器失败解释成整族无效。

保留C76.4与合法六API/HiF4五字段。Q/K/V动态调用相互独立，不能偷读另一API本次输入、利用全局调用顺序或保存校准token答案；动态无Gram、无求逆、无新增候选搜索循环。校准可以共同使用Q/K/V学可部署参数。V量化器保持不变，但其现有误差必须纳入输出目标。

优先序：**Q/K联合输出残差驱动的规则学习 → 结构化变换求解器（备选）**。不以继续给A-GR1降本或修小计时差作为突破主线。

## 4. 阶段B主线：Q/K联合输出残差驱动的校准规则

论文依据：[BoA（ICML 2025）](https://arxiv.org/html/2406.13474v3)利用Attention重构与二阶近似指导量化补偿；[YAQA（ICML 2026）](https://arxiv.org/abs/2505.22988)研究输出敏感的舍入与Kronecker Hessian近似。二者原算法主要量化权重，以下是面向本题的迁移假设，**不是现成可用实现，也不继承论文收益**。

### 要解决的新问题

用完整部署输出误差优化一个可校准编译的Q/K量化规则，而非分别压低Q/K operand MSE、amax或只最小化无符号敏感度。

以冻结父量化输出为展开点：`O0 = softmax(Q0 K0^T / sqrt(d)) V0`，`r = O0 - Oref`。改变Q/K后的logit增量为

`deltaZ = (deltaQ K0^T + Q0 deltaK^T + deltaQ deltaK^T) / sqrt(d)`。

局部候选模型为 `||r + J_softmax(Z0)[deltaZ] V0||²`。它保留父残差的线性项与Q/K共同改变；仅用`K^T K`、对角importance或`||deltaO||²`会遗漏部分目标。该式仍是softmax局部近似，不当成精确二次目标；每次研究结论都用完整合法hard encode/decode后的Attention MSE核验。

### 固定开发步骤

1. 校准阶段一次形成父残差与可分解敏感度统计；不物化全token×channel Hessian，采用按既有GQA/量化块组织的统计。GQA共享K所服务的全部Q heads必须纳入固定聚合。
2. 合同明确一个低维、输入可计算的Q/K合法舍入策略，并用上式指导校准学习。不得把每个校准token的最优码存成查表；也不能把动态逐码补偿循环称为离线编译。
3. 在小形状上验证代理的方向与真实输出变化、统计维度、GQA共享、mask/长度、五字段层级合法性；若编译后全部退回原码，只能说明该规则无可达作用。
4. 合同通过后，在执行计划中预注册**一个**固定参数化、拟合轮数、fold聚合、求解器与控制配置，才构建候选。该细节由接口审计决定，本文不虚构未经验证的轮数或自由度；不扫描其邻域。

重点风险：联合信息可能无法压缩成独立动态API可执行的规则；局部模型可能不能跨越硬量化边界；共享scale会使独立舍入无效。出现这些证据时保存反例、关闭具体实现，不为到0.80不断加搜索。

## 5. 阶段C备选：结构化变换，从参数化上控制求解成本

依据[FlatQuant（ICML 2025）](https://arxiv.org/html/2410.09426v2)：使用Kronecker结构表示可学习变换，优化量化重构。作为备选研究`M = M1 ⊗ M2`，在校准中学习、最终编译至合法Q/K互逆字段。因子维度采用head_dim的最接近平衡整数分解这一固定规则，不扫尺寸，不新增层/role专属路由。

**不是A-SR1重试**：不要求复现一般矩阵训练轨迹，不是用SVD因子替换同一inv实现；候选改变参数空间和求解算法。也不直接以旧amax目标跑两个小矩阵便称新机制：合同必须说明实际输出重构目标、硬量化求解方式及与已关闭rotation/gauge实现的差异。若只能得到旧参数邻域，结束备选审计，不注册候选。

必须保持量化前乘积不变，验证K center同步变换、GQA与异常回退；保留V和C76.4。既有A-GR2学习率/归一化扫描、K定心、Q偏置、V码分配不重开。结构本身是否保留足够表达力未知，不预言0.80或官方收益。
