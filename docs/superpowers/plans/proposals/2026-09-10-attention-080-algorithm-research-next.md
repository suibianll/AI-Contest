## 1. 目标与口径

**研发里程碑**：4B Attention 面板 `overall_mean ≥ 0.80`。
`gain_i = 1 − MSE_PLAYER_i / MSE_STD_i`；`overall_mean = mean_i(gain_i)`（72 例等权）。

- 口径是**逐例增益的均值**，不是 `1 − mean(mse_p)/mean(mse_s)`（后者 0.4814）。
- 禁止改分母、重加权、删负 case、只报 fit 或接受层。

| 项 | 值 | 证据等级 |
|---|---|---|
| 当前 `overall_mean` | **0.5340**（n=72，min 0.2261 / max 0.7971） | 已提取报告，未重跑 |

| 分布 | 层22/15 占缺口 55%；按长度 0.511–0.553、按划分 test 0.531 / val 0.537 | 同上 |

**外部锚点 21071 / 283 s**：仅保留报告数字；相对本根分差为 2553。
整包秒数不能定位子机制成本，历史候选不存在可外推的“分/秒兑换率”。不得据此排除新增校准训练、搜索或其他实质算法；其完整分数与时间交官方裁决。

**以下列出本轮相关条款，不替代六 API、HiF4 格式与合法 state 的完整合同。**

| 出处 | 内容 | 状态 |
|---|---|---|

**L180（Attention 场景）是书面要求，不是可选路线**：

> **利用校准 Q、K、V 数据生成在线量化所需状态**，并分别对在线 Q、K、V 动态 HiF4 量化，
> 使量化后的 Attention 与参考 Attention 之间的 **MSE 尽可能低**

**state 格式**：None/bool/int/有限浮点/str/CPU Tensor/list/tuple/str-key dict；深度 ≤8；
**节点数 ≤4096**；dtype 限 11 种；无 NaN/Inf/复数/梯度。
→ 一个 256×256 f32 矩阵只占 **1 个节点**；节点数不等于字节数，仍须核验 state 合法性、内存与执行成本。

**本项目执行边界**（来源见 AGENTS；不得误写成赛制禁令，也不得由此推导整族无效）：
动态 API 执行校准编译规则，不引入校准搜索、完整矩阵求逆或无界 Python 候选循环；Attention 动态端另禁止 Gram contraction 和候选循环。已计分动态求逆例外按 AGENTS 保留。
本计划候选按“本次输入 + 编译 state”设计，不依赖跨 API 调用顺序；这是本计划的部署设计，不是赛题信息隔离定理。

`API_INCOMPATIBLE` **仅**适用于：部署表达式既无法由「本次输入 + 编译 state」算出，
**且**校准期也无法编译出等价规则。

### 2.1 state 是信息通道，三路 state 之间没有隔离

```
hif4_calibration_attention(calib_qkv_list, …) ──一次调用──▶ (q_state, k_state, v_state)
        ↑ 看到全部校准 Q、K、V 与 head 参数
```

| state | 可以编码 |
|---|---|
| `q_state` | Q 的函数，**以及 K、V 的任意函数** |
| `k_state` | K 的函数，**以及 Q、V 的任意函数** |
| `v_state` | V 的函数，**以及 Q、K 的任意函数** |

Linear 侧：`activation_state` 由 **`hif4_calibration_and_quantize_weight`** 产出，
它同时拿到 **W 与全部校准激活** → 可携带 W 与 `A@W` 的函数。

**隔离的只是"本次输入"，不是"已知的结构"。** 任何"需要联合信息才能算"的量，
可研究校准期编译；部署表达式仍须满足合法 state、官方编码格式及 AGENTS 动态路径约束。

### 2.2 结构性不对称：Q 行局部，K 与 V 不是

| 扰动 | 影响的输出行 | 可编译形式 |
|---|---|---|
| **ΔQ**（token t） | **只有行 t** | 局部一阶度量可写成 `d×d`，其数值依赖当前 Q/K/V；编译近似须验证 |
| **ΔK**（token j） | 通常影响所有行 | 跨 token 耦合不等于无法编译；固定维度近似或输入条件化规则尚需具体推导 |
| **ΔV**（token j） | 通常影响所有行 | 固定 A 时为线性加权；相对位置核仅是一种待验证近似，不是唯一形式 |

## 3. 目标函数的代数结构

```
Z = QKᵀ/√d, A = softmax(Z), O = AV
ΔZ = (ΔQ·Kᵀ + Q·ΔKᵀ + ΔQ·ΔKᵀ)/√d
ΔA = softmax(Z + ΔZ) − softmax(Z)
ΔO = ΔA·V + A·ΔV + ΔA·ΔV                 （精确）
ΔA ≈ J_softmax,Z[ΔZ]                      （一阶近似）
```

| 操作数 | 它的误差在输出里被什么加权 |
|---|---|
| Q | K、softmax Jacobian、V |
| K | Q、softmax Jacobian、V |
| V | 注意力概率 A |

固定层级下硬码选择离散，穿过 round 的无穷小导数通常为零；完整 Attention 目标含 softmax，不能称为双线性目标。
平滑松弛、STE 或梯度辅助离散求解可作为求解工具，其下降不保证硬输出改善；必须另测实际编码与输出变化。

**operand MSE 不能替代输出目标的诊断**：V 侧共模仅占 V 误差能量 **2.8%**，去掉它 gain
0.5340 → 0.5751（**+0.0412**）；而均匀加权代理降 **−77.89%** 时真实输出只动 **+2.60%**。

### 4.10 的解读（本轮最重要的新读数）

所测 `diag` 与 `metric` 来自同一个平均度量；在该扰动样本上的相关性，前者更高。
“平均使耦合信息相互抵消”仅为待验证解释（D），不是已测事实；相关性相近也不证明与根 `importance` 等价。
本实验不证明不存在更好的聚合或输入条件化编译，更不证明 Q/K/V 侧无法使用内容信息。

## 8. 强制纪律（每条对应一次已发生的事故）

1. 精度候选记录 attempted/accepted、硬码及最终输出变化；区分实现可达与实际候选是否回退。参数微调不要求每次跨越硬码边界；纯降时按 AGENTS 的等价输出例外执行。
2. **gate 拒收是结果，不是证据。** 每卡必须带**独立于下游效果**的检查：
   代数不变量 / 度量相关性 / 核拟合度 / 码移动计数。（← 缺陷 #13/#14/#16）
3. **任何为分析而重算的被评测函数必须从 `evaluator/` 读源码**，不得凭领域直觉重建。
   （← 缺陷 #19：给 attention 加了评测器没有的因果掩码，污染过真实读数）
4. **判据必须与规则实际作用的尺度一致。** 规则在单 case 内作用 → 判据必须是**层内/例内**统计量，
   不是跨层合并统计量。（← 缺陷 #25：CM-1 首跑因此得到假 PASS）
5. **本地运行不得并发**；输出路径每卡独立、带运行标识。（← 缺陷 #17）
6. **一切探针用 `.venv\Scripts\python.exe`**（CUDA）；系统 `python` 是 CPU-only。
   （← 缺陷 #26）
7. **先冒烟再全量**：单层/单 token 几秒跑通，再放全量。（← 缺陷 #21–#23）
8. **不用盲写 `str.replace` 改脚本**：断言只查出现次数不查落点。（← 缺陷 #24）
9. 父一律取**不可变归档**；纯追加构建；一个固定配置，预注册后不扫邻域。
10. 不改写旧产物；更正写入新日志。不删除 `artifacts/official_eval/cache/qwen3.5-4b-proxy-v2.pt`。

**仪器缺陷台账**：`docs/instrument-defect-ledger-2026-09-11.md`（26 条，其中 **17 条"不会自己暴露"**）。
未独立核验的读数明确标注其局限；不把局部推导核验提升为整族结论，也不为已绑定 SHA 的官方回传新增核验门。
