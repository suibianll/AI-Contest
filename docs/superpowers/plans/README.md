## 下一步

1. Attention A-SR1：审计并复用每步SVD投影分解，减少训练内重复求逆；保持32步与原目标/gate；先验证逐位等价，无法保持则关闭本卡，不自动转为有精度风险的新算法。
   → **已按此执行：审计即关闭，NUMERICAL_NON_EQUIVALENCE（2026-09-10）。** 因子构造的 `P = U diag(1/s) Vh` 与父的 `inv(m)^T` **每层每步都不逐位相同**（最差相对差 4.4e-06）；传播到编译轮换（最大绝对差达 8.2e-02）与动态 Q 五字段（每层每字段全不同），**层 8 的 gate 判定由接受翻转为拒绝**。固定方案内不可修复（要逐位相同只能调用 `inv()`，那正是本卡要消除的操作）。未跑六 shard、未占版本号。见[执行记录](../../../logs/execution/2026-09-10-attention-asr1-factor-reuse.md)。
2. Linear L-MC1：**已完成并归档 v240**（`2c344722…`）。固定度量重建移入校准；对 v237 根 **336/336 精确零**；但它是**搬运而非消除**工作——校准 +50.0 ms/次、动态 −28.3 ms/次，**平衡点 ≈255 次动态调用**；官方动态调用次数仍是缺失事实（本地净省约 0.95 s，官方若只有 50 次则净增约 5.8 s）。关键发现：**stride 也是等价性的一部分**（`cholesky_inverse` 返回转置 stride，`.contiguous()` 会破坏等价）。
3. Attention精度归因：复用A-GR2已有证据，明确训练不降与gate拒绝的不同原因，不重试参数邻域，可立即开始，不依赖A-SR1完成。

两线从最高分完整根独立构建，不互等官方；本地耗时占比或提速不显著不构成关闭条件；单GPU执行串行。本次仅制定计划，尚未启动实现或评测。
