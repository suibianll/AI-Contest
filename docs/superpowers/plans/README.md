见[超时记录](../../../logs/execution/2026-09-11-v241-v242-vk-official-timeout.md)。
两卡是同一机制的两种粒度（`diff` 仅 30 行），各自独立提交、各自超时；根未切换。
**关掉的是这两个实现，不是 VK-1 方向**（计划 §7）。该次回传的方法论教训已写入计划 §6.1：
v242 的"落进余量"算术（`+0.0117 s/次 × 250 用例 ≈ 2.9 s < 11 s`）三个支点只有"一 case 一次 V 调用"可靠，
**case 数取自 `SOURCE_UNBOUND` 的用户报告且与更早记录的 200 Attention 冲突**，
**单次成本是 GPU 实测而官方判题是鲲鹏 920B CPU**。

**侧隔离定价通道已全部回传：`standard-linear_v242-attn` 官方 `14098 / 250s`，倒扣 307 分，
VK 机制关闭（2026-09-11 回传）**。用户回传「linear_v242 官方分数 14098，时间 250」。
对照基线标准 Linear + R3 `14405 / 238s`，**Δ = −307（−2.13%）**；相对 v195 `14426` 为 **−328**。
侧隔离是单变量口径（与基线共用逐字节同一标准 Linear codec），故 `−307` 就是该 Attention
机制的官方效应——**不是"值 0 分"，是"倒扣"**。这是该通道上**幅度最大且唯一为负**的一次读数
（此前全部落在 `0 … +50`）。

VK 机制至此四次尝试：完整包 v241/v242 `TIMEOUT`、姊妹侧隔离探针 `standard-linear_v241-attn`
`TIMEOUT (>300s)`、本探针 `14098`。**故 VK 机制关闭**（含 per-Q-head / per-KV-group 两个已测
粒度与参数邻域；共享版是代数重参数化，同一最小化点，不构成两个机制），且**该机制的降本工作线
到此为止**——`250s` 证明降本在时间上确实有效（`>300s` → `250s`），**但进限也救不了 −307**。
详细登记见[回传记录](../../../logs/execution/2026-09-11-vk242-side-isolation-official.md)。

**本地面板与官方方向相反、幅度差两个量级**：v241 完整六 shard `+0.004547`（**六片全正**）、
v242 shard0 `+0.005159`（12/0/0），官方 `−307`。这是 AGENTS §2「本地读数只作机制诊断、
不设提交或晋级阈值」迄今**最强的支持案例**（前例 v229 本地 `+0.014923` → 官方 −2）。
**不解释成因**（无测量支持）。**不推广**为"V 侧码分配整族无效"或"位置信息不能用于选 V 码"
——被证伪的是这一**具体形式**，后续需**新机制**而非调参；AGENTS §3 的 2026-09-10
校准期 V 码分配**授权不受影响**。

**姊妹探针 `standard-linear_v241-attn` 同回传为 `TIMEOUT (>300s)`。** 这是**第二次**侧隔离探针
超时（首次 v165/v161，2026-09-03），此前侧隔离时间上限 v192 `272s`、基线 v195 `243s`。

**这次回传更正的是开卡时的前提，不只是加一条结果。** 本入口与构建记录当时写的理由是
"侧隔离包更小、**余量充裕**，余量约 57～62s，正是完整包缺的那个量级"——**该前提被证伪**：
那 57～62s 不是通道的固有属性，而是**此前被测机制都很便宜**（234～272s）的结果。
**侧隔离包同样有 300s 硬限，Attention 成本跟着机制走**，所以**能否拿到分数由机制成本决定，
不由通道决定**；时间墙会伸进诊断通道内部。这是[侧隔离分登记](../../../logs/execution/2026-09-09-standard-linear-attention-side-scores.md)
§5「侧隔离只能测分不能测时间」的加强版。**今后开侧隔离卡前，先按机制成本判断该通道是否还可用。**

**侧隔离分不晋级、不与完整分相加**（AGENTS §2）。**不反推官方计时方差、不推导本地→官方
换算系数、不做降时预算**（v241 侧隔离 `>300s` 与本次 `250s` 之间差多少未知）。
