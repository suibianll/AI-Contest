## 1. 本计划只有两个目标

1. **提高精度：Linear mean 目标为 `0.8`。** Attention 保留已经取得的有效增益，并通过降低算法复杂度为 Linear 释放时间。
2. **控制时间：官方端到端运行时间严格小于 `300s`。**

本计划不再设置 screen 分数、单 role 回退、rank、block、state 节点数、本地秒数换算等额外晋级门槛。所有实验只记录两类结果：精度变化和运行时间变化。最终保留精度更高且能够满足官方时间限制的实现。

### 2.1 Linear 到 0.8 的数学距离

\[

### 2.2 `A@W` 放开后的核心机会

令

\[
Q(A)=A+E_A,\qquad Q(W)=W+E_W.
\]

最终输出误差为

\[
Q(A)Q(W)^T-AW^T
=E_AW^T+AE_W^T+E_AE_W^T.
\]

现有算法主要分别让 `Q(A)` 接近 `A`、`Q(W)` 接近 `W`，没有直接优化上述三项之和。既然 `A@W` 已经可以自由使用，Linear 主目标改为

\[
\min_{Q(A),Q(W)}\|Q(A)Q(W)^T-AW^T\|_F^2.
\]

算法可以主动让激活量化误差和权重量化误差在输出空间中抵消，而不要求两个 operand 各自最接近原值。

### 2.3 Attention 超时的直接原因

v98/v100 在 Attention calibration 中约执行 35 次候选评分，每次都在完整 calibration 序列上重新计算 `QK^T`、softmax 和 `P@V`。其复杂度近似为

\[
O(N_{candidate}\sum_i H_qT_i^2d).
\]

官方 calibration 长度 `[10,128,512,1024,1024]` 的 `\sum T_i^2` 是旧本地两个
128-token 样本的约 `72.5` 倍。新评测系统已经实测：v098 的 Attention calibration
为 `294.876s`，v100 为 `296.271s`，尚未进入 200 次动态 Q/K/V 就已经占满官方时间。
相比之下，v084 的 Attention calibration 为 `43.817s`。这证明 v98/v100 超时是算法复杂度
问题，不是实现常数问题。Attention 必须先改成固定预算候选搜索，不能继续在完整长序列上
评分全部候选。

### 2.6 两个目标的误差量级与直接结论

分数 `g=1-MSE_player/MSE_std`，因此不能只比较分数绝对差，还要看剩余误差需要下降多少：

| 场景 | 当前 | 目标 | 当前剩余误差 | 目标剩余误差 | 必须消除当前剩余误差 |
|---|---:|---:|---:|---:|---:|
| Linear | `0.5073546` | `0.8` | `0.4926454` | `0.2` | **`59.41%`** |
| Attention | `0.7159420` | `0.834` | `0.2840580` | `0.166` | **`41.56%`** |

结论如下：

1. **Linear 只调当前参数不能达到 0.8。** alpha、offset、block 数、sweep 数、gain 和候选槽位
   只改变同一 block-diagonal 表示中的搜索位置，不增加跨 block 表达能力，也没有改变当前
   `Q(A)`/`Q(W)` 误差耦合方式。v135–v139 已经显示该局部空间进入平台或回退。
2. **Attention 在严格保持 v138 在线算子图时不能合理预期恢复 0.834。** 静态 v86 相对 v138
   只高 `0.003754`；而已记录的一次动态 Gram sweep 从 `0.715942` 量级提升到 `0.828014`
   量级，第二次 sweep 再到 `0.834256`。版本之间不只一个变量，不能把差值当成严格消融，
   但现有证据一致表明主要增益来自 Gram-aware 动态码字修正，而不是 alpha/angle 调参。
3. Linear 要到 0.8 必须更换表示和优化结构；Attention 若坚持等复杂度，唯一有理论机会的
   方向是把静态 Gram 目标编译进一个与当前变换等成本的 Q/K 互逆变换，而不是扩大参数网格。

## 3. 总体算法结构

新的提交路径分为三个相互配合的部分：

1. **Attention 固定预算搜索**：保留有效的 reciprocal balance、K-centering、rotation 和 GQRB，但候选搜索不再随完整序列长度平方增长。
2. **Linear 输出监督联合量化**：使用 `AW` 直接训练合法 HiF4 `Q(W)`，并让在线 `Q(A)` 直接最小化输出误差。
3. **统一时间压缩**：所有大矩阵目标都转换为缓存统计、低秩因子、分块增量或少量真实输出复算，最终以官方端到端时间为准。

## 4. Attention：保留精度并消除长序列超时

### A0. 当前根的硬约束：只替换，不叠加

v138 已经完成时间结构切换。后续所谓“Attention 不增加复杂度”具体指：

- 候选数量不增加，代理/shortlist token 仍为 `128`，统计 token 仍为 `256`；
- QK、softmax、PV 的调用次数不增加，不增加 full-length 候选复算；
- 动态 Q/K/V 保持无 Gram、无 coordinate sweep、无 PAWV；
- 只替换现有候选槽中的 alpha、block size、width-2 rotation angle 或确定性采样位置；
- 复用现有 RMS、covariance 和 importance 统计，不新增长序列矩阵乘和在线 state 张量。

第一目标是在这一完全等成本搜索空间内从 `0.715942` 回收到至少 v86 的 `0.719696`。可测试的
替换包括 `block 16 -> 8/4`、在同样两个 angle 槽内替换 `±π/8`、以及在同样两个 alpha 槽内
替换当前 `(0.25, 0.5)`；每次只换现有槽位，不新增候选。若要回到 `0.83+`，现有证据表明
仅靠这些参数替换不可行；必须使用 A6 的 Gram 编译变换，或者承认需要恢复动态 Gram。

### A1. 固定预算代理搜索

重写 `hif4_calibration_attention` 的候选评分数据流：

1. 完整 calibration Q/K/V 只用于一次线性统计，例如 RMS、二阶矩、head importance 和长度信息。
2. 从每个 calibration sample 确定性采样固定数量 token，构造代理 Q/K/V。
3. alpha、center、signed-Hadamard、rotation、GQRB 全部在代理数据上评分。
4. 代理阶段优先使用 Q/K 重建误差、logit 误差和压缩输出误差，不对所有候选构造完整 `T×T` Attention。
5. 只对代理排序靠前的少量候选执行真实 Attention 输出复算；真实复算仍使用固定长度子样本。
6. 完整 512/1024-token calibration 不进入候选循环，因此候选数不再乘上 `T^2`。

目标复杂度变为

\[
O(N_{proxy}T_{proxy}^2d+N_{short}T_{short}^2d+\sum_iT_id),
\]

其中 `T_proxy`、`T_short` 是固定预算，不随官方最长序列继续增长。

### A2. 缓存候选公共量

对所有候选共用的数据只计算一次：

- dense reference 的采样输出；
- V 的普通 HiF4 结果；
- GQA head 映射；
- RMS ratio；
- Q/K importance 的基础统计；
- rotation signs、Hadamard 和固定 GQRB 矩阵；
- 代理数据的 reshape、head view 和索引。

候选之间只改变 multiplier、center、rotation 或 mixing，不重复解码 NVFP4、不重复建立相同 reference。

### A3. GQRB 低成本化

GQRB 是 v98 相对 v84 的主要 Attention 精度来源，继续保留，但改变选择方式：

1. 固定角度、Hadamard、covariance rotation 作为候选集合；
2. covariance 只在代理 token 上计算；
3. 第一轮用 logit/重建代理排序；
4. 第二轮用固定短序列真实 Attention 排序；
5. 选中的 mixing 写入 CPU state，在线只执行一次小块矩阵乘。

### A4. PAWV 重新定位

新协议中，v098 的 Attention 为 `0.833573`，增加 PAWV 后的 v100 为 `0.833617`，提升
约 `0.000044`；与此同时动态 V 从 `1.551s` 增加到 `10.629s`，API total 从
`406.681s` 增加到 `417.747s`。新路径先移除 dense PAWV，保留 v098 的快速 V 路径，
随后只研究不会恢复全序列候选 `T^2` 成本的形式：

- 代理序列上的位置权重；
- 按长度保存的统计摘要；
- 流式或分块计算的 row importance；
- 直接从 Q/K 二阶统计预测 V row weight。

PAWV 是否保留只由最终精度和总时间结果决定。

### A5. 同复杂度 Attention 精度回收

按单变量替换执行，不改变候选数或在线调用图：

1. 固定 alpha 与 angle，仅把当前一个 `block=16` 槽替换为 `8`，再单独比较 `4`；
2. 固定候选数量，在两个 width-2 angle 槽中比较 `±π/8`、`±π/4` 及一正一负组合；
3. 固定四个 alpha/rotation 组合槽，比较 `(0.25,0.5)`、`(0,0.5)`、`(0.5,0.75)` 的替换；
4. 对相同候选输出使用更贴近最终 Attention output 的现有 shortlist loss 重新选优，不增加复算；
5. 只保留完整 450-case 下 Attention 提升且 API 时间与 v138 测量噪声相当的替换。

这条路径的合理预期是回收静态路径内部的千分位到百分位误差，不承诺恢复 `0.834`。动态 Gram、
coordinate sweep、PAWV 和扩大候选集均暂缓，因为它们正是 v129–v131 官方超时 family 的主要
复杂度差异。

### A6. 等复杂度恢复 0.834 的唯一结构候选：互逆 Gram 平衡变换

当前高精度路径保存 calibration Q/K 的 Gram，并在每个动态 Q/K 上做坐标 sweep；v138 删除
这一步后，普通 HiF4 只按元素/层级重建误差编码。要在不恢复 sweep 的情况下逼近同一目标，
需要在 calibration 阶段把 Gram 的非对角耦合编译进现有 Q/K 变换。

对每个 GQA group 和通道块累计

\[
G_Q=\sum_f Q_f^TQ_f,\qquad G_K=\sum_f K_f^TK_f.
\]

学习可逆块变换 `T`，部署为

\[
Q'=QT,\qquad K'=KT^{-T},\qquad Q'K'^T=QK^T.
\]

变换后的两个量化误差度量分别由

\[
G'_Q=T^TG_QT,\qquad G'_K=T^{-1}G_KT^{-T}
\]

决定。目标不是继续枚举固定角度，而是直接最小化 `G'_Q`、`G'_K` 的非对角能量和条件数。
SPD 情况下可先求满足 `P G_Q P = G_K` 的几何均值平衡矩阵

\[
P=G_Q^{-1/2}(G_Q^{1/2}G_KG_Q^{1/2})^{1/2}G_Q^{-1/2},
\]

再把它分解为与当前 `block-Hadamard + width-2 mixing` 相同 stage 数的 2×2 reciprocal
butterfly。Q 保存各 stage 的 `T`，K 保存 `T^{-T}`；两边仍各执行一次现有 transform/mixing
路径，不增加候选数、QK/softmax/PV 次数、动态 Gram state 或 coordinate sweep。现有固定
angle/covariance 槽被该解析候选**替换**，不是叠加。

该算法成立的原因是：如果变换后两个 Gram 近似对角，普通逐坐标 HiF4 已接近 Gram 目标，
原动态 coordinate sweep 的作用会显著缩小。需要同时记录非对角比率

\[
\rho=\frac{\|\operatorname{offdiag}(G'_Q)\|_F+\|\operatorname{offdiag}(G'_K)\|_F}
{\|G'_Q\|_F+\|G'_K\|_F}
\]

与真实 Attention 输出误差，判断静态编译覆盖了多少 Gram 增益。

**可达性判断**：这是严格等复杂度下唯一有希望获得大幅提升的新表示，但目前没有实测证据
证明它能把 `0.715942` 完整恢复到 `0.834`。恢复目标要求消除 `41.56%` 的剩余误差，远大于
静态参数调节已观察到的约 `0.003754` 分数空间。因此当前结论是：**调参不能恢复；互逆 Gram
平衡在理论上可能恢复一部分甚至大部分，但 0.834 尚未证明，且大概率仍需至少一次压缩后的
Gram-aware 码字修正。**若最终需要该修正，它虽然可向量化为固定 block 的一次 pass，但相对
v138 仍增加实际运算量，不能再称为“复杂度不变”。

## 5. Linear：以 `AW` 为教师目标的联合量化

### L0. 建立合法码域可达性 oracle

Oracle 只用于回答 0.8 是否存在合法 HiF4 解，不作为新的限制：

1. **Activation oracle**：固定当前 `Q(W)`，直接优化合法 `Q(A)`，使 `Q(A)Q(W)^T` 接近 `AW^T`。
2. **Weight oracle**：固定部署 `Q(A)`，直接优化合法 `Q(W)`，使 `Q(A)Q(W)^T` 接近 `AW^T`。
3. **Joint oracle**：交替优化合法 `Q(A)` 和 `Q(W)`，绘制迭代轮数、精度和时间曲线。
4. 使用新协议 cache 中相同的 calibration/test tensor 和 case tuple，分别记录同数据上限、
   calibration-to-test 泛化结果和完整 `official-shape-v1` 结果。

该 oracle 会区分三个问题：HiF4 码域是否有能力达到 0.8、calibration 是否能学到该解、以及该解能否在 300 秒内近似实现。

### L1. 输出监督权重量化

固定部署激活 `Z=Q(A)`，对每个输出权重行求解

\[
\min_{w_q\in\mathrm{HiF4}}\|Zw_q-Aw\|_2^2.
\]

实现方式：

1. 对每个 calibration fold 生成实际部署的 `Q(A)`；
2. 缓存教师输出 `Y=AW^T`；
3. 用 `Z^TZ` 和 `Z^TY` 构造离散坐标增量；
4. scale、lv2、lv3、sign、mantissa 作为一个合法层级整体更新；
5. 按输出 row chunk 批量求解，避免长期保存全部输出；
6. 更新一个 block 后增量更新 residual，不重新计算完整 `ZQ(W)^T`；
7. 使用多个 calibration fold 的合并输出目标，减少单样本拟合偏差。

这条路径与现有 Weight-HSDQ 的根本区别是：教师目标是 `AW`，输入是实际 `Q(A)`，因此权重会主动补偿激活量化造成的系统误差。

### L2. 输出监督动态激活量化

固定 `W_q=Q(W)`，对单行激活 `a` 和合法 HiF4 行 `q`，目标为

\[
J(q)=\|qW_q^T-aW^T\|_2^2.
\]

展开得到

\[
J(q)=qHq^T-2qDa^T+\mathrm{const},
\qquad H=W_q^TW_q,\quad D=W_q^TW.
\]

完整 H、D 只用于 oracle。部署实现依次研究以下压缩表达，并记录精度与时间：

- 64×64 block diagonal；
- block diagonal 加低秩残差；
- selected cross-block columns；
- block-circulant/butterfly 结构；
- 直接保存 W、Wq 因子并用稀疏增量恒等式计算真实输出变化。

动态过程先生成普通 HiF4 parent，再用输出目标修改最有价值的码字。候选改变 `delta=q_candidate-q_parent` 时，使用

\[
\Delta J=2\delta(Hq-Da)+\delta H\delta^T
\]

增量计算，而不是为每个候选重新执行 `A@W`。

### L3. 零在线增量的输出感知对角补偿

当前在线已经执行一次逐输入通道 `output_gain` 乘法，因此该候选不增加任何在线算子，只把
calibration 中的 gain 目标从 weight reconstruction 改成最终输出误差：

\[
g^\star=\arg\min_g\sum_f\|A_f\operatorname{diag}(g)W_q^T-A_fW^T\|_F^2.
\]

在现有 calibration 行上累计每个输入通道的分子/分母或对角 Newton 统计，使用 cross-fold
数据选择收缩系数；部署仍然只有现有的 `dense *= output_gain`。v139 已验证这一近似：
Linear 为 `0.507278`，相对 v138 回退 `0.000041`，因此拒绝。结论不是继续扩大 gain 搜索，
而是连续 block 代理与最终离散 HiF4 仍有错配；后续必须让固定预算选择更贴近真实离散下降。

第二项是在保持 `_OUTPUT_WEIGHT_HSDQ_BLOCKS=4`、同一 sweep/coordinate 数的条件下，把 block
优先级从局部启发式替换为跨 fold 的真实输出残差下降排序。它重新分配固定预算，不增加在线
复杂度或 calibration 循环数。

### L3b. 连续输出补偿中心（后置）

在离散量化前先求连续目标

\[
a^\star=\arg\min_z\|zW_q^T-aW^T\|_2^2.
\]

不在线求完整逆矩阵，而是在 calibration 阶段学习低秩修正：

\[
a^\star\approx a+aUV^T.
\]

在线以 `O(NKr)` 应用 rank-r 修正，再把修正后的连续中心编码成合法 HiF4，最后由 L2 做离散输出精修。由于它会增加在线复杂度，只在输出感知 gain、固定预算 block 重排和 L4 等零在线增量方案用尽后再研究。

### L4. 输出监督等价变换

学习可逆变换 T：

\[
A'=AT^{-1},\qquad W'=WT^T,qquad A'W'^T=AW^T.
\]

T 使用在线成本可控的结构：

- diagonal balance；
- permutation；
- signed-Hadamard；
- butterfly；
- 小块 Givens rotation。

与现有 BOAT 不同，候选 T 直接按量化后的 `Q(A')Q(W')^T` 与 `AW^T` 的误差选择。变换学习只发生在 calibration，在线只应用最终一个 T。

### L5. 联合交替优化

将 L1–L4 组成短链联合优化：

1. 初始化等价变换和普通 Wq；
2. 根据当前 Wq 生成输出监督激活状态；
3. 得到 calibration Q(A)；
4. 用 `AW` 更新合法 Wq；
5. 重新计算 H、D 和低秩补偿；
6. 再更新 Q(A)；
7. 记录每轮精度和时间，选择最终双目标结果。

### L6. 按 Linear 结构分配计算

不同 role 使用同一输出目标，但采用不同压缩方式：

| role/形状 | 主要误差 | 重点算法 |
|---|---|---|
| q、k | 权重侧较强 | 输出监督 Weight-JDRQ、层级整体更新 |
| v | 双侧耦合 | 等价变换加联合优化 |
| o | 激活侧较强 | 低秩激活补偿加输出精修 |
| fc_gate | 双侧均明显 | 联合 Q(A)/Q(W) |
| fc_up | 激活侧主导 | 连续补偿中心和动态输出目标 |
| proj / 宽输入 | 激活侧、跨 block | 低秩/结构化 H、D 和稀疏真实增量 |

路由由 weight shape、calibration 统计和当前输出残差决定，不要求所有层使用相同计算量。

### L7. 为什么当前框架只调参到不了 0.8

v138 的动态激活目标实质上是把完整输出二次型

\[
J(q\mid a)=q^THq-2q^TDa+\mathrm{const},\qquad
H=Q(W)^TQ(W),\quad D=Q(W)^TW
\]

截断为独立 64 通道块：

\[
H\approx\operatorname{blkdiag}(H_1,\ldots,H_B),\qquad
D\approx\operatorname{blkdiag}(D_1,\ldots,D_B).
\]

同时，输出监督 Weight pass 只精修 4 个 block，BOAT 只从有限 diagonal/Hadamard 候选中选
一个变换。调 alpha、offset、block 数、sweep 数和 gain 仍然受以下五个结构限制：

1. 看不到 `H_bc`、`D_bc (b≠c)` 的跨 block 输出耦合；
2. 不能学习新的输入坐标系，只能在固定 Hadamard/seed 网格中选择；
3. activation 的 scale/lv2/lv3/mantissa 层级没有按最终输出做联合 block 决策；
4. `Q(W)` 和 `Q(A)` 只做短链局部更新，不能系统利用两侧误差抵消；
5. q/k 与 FFN 使用基本相同的表示，但旧诊断显示它们的误差主侧完全不同。

近期同框架证据为：v134 `0.5073195`；Jacobi calibration+dynamic 的 v135 `0.500812`；
dynamic-only v136 `0.500132`；多一轮 calibration sweep 的 v137 `0.507163`；连续 output gain
的 v139 `0.507278`。历史 precision-only 路径即使把低秩、跨 block、hierarchy sweep 叠到
`2653s`，Linear 也只有约 `0.50976`（旧协议，只作为平台证据）。因此工程结论不是“参数尚未
搜够”，而是**当前表示族已经饱和**。

旧 L0 单侧诊断（不同于当前 `official-shape-v1`，只能用于结构判断）为：

| 诊断臂 | Linear |
|---|---:|
| 当前双侧量化 | `0.523019` |
| 权重无损、激活保持当前量化 | `0.704170` |
| 激活无损、权重保持当前量化 | `0.820357` |
| 双侧无损 | `1.0` |

它说明权重单侧即使完美也不到 `0.8`；激活单侧完美只比 `0.8` 高约 `0.02036`。若把该诊断
近似分解，保留当前权重时需要消除约 `93.15%` 的 activation-induced 剩余误差才能到 0.8，
几乎等于“激活无损”。这不是普通参数微调能完成的，必须同时改善激活表示、权重表示和误差
抵消。严格数学结论仍由当前协议的 legal Joint oracle 给出，但工程判断已经明确：**只调参
不可达 0.8。**

### L8. 输出对齐互逆 Butterfly（ROAB）：首先更换表示

将当前固定 BOAT 替换为学习型、严格等价的结构变换：

\[
T=D\prod_{s=1}^{S}B_s,\qquad
A'=AT^{-1},\quad W'=WT^T,quad A'W'^T=AW^T.
\]

每个 `B_s` 是一层互不重叠的 2×2 可逆 butterfly；stage 数固定为当前 Hadamard/FWHT 的
stage 数，因此在线不叠加第二套变换。calibration 直接最小化真实合法 HiF4 输出：

\[
\min_T\sum_f\left\|A_fW^T-
Q_H(A_fT^{-1})Q_H(WT^T)^T\right\|_F^2.
\]

具体求法：用连续梯度或 2×2 Procrustes 生成 `B_s`，但每一步都用实际 HiF4 codec 重编码并
按两折真实输出排序；最终只保存一个 `T^{-1}` 的 structured stage state 和已经变换的静态
`Q(W')`。这与继续扫 Hadamard seed 不同：它可以主动把 activation outlier、weight sensitivity
和两侧量化误差旋转到可抵消的坐标中。q/k 使用较小 block；`fc_up/proj` 使用完整 64 通道
butterfly，因为旧诊断中它们最 activation-dominant。

ROAB 是 Linear 首个真正可能产生数量级变化、同时不增加动态渐近复杂度的算法：它**替换**
当前 FWHT，而不是叠加。但 calibration 中的变换学习仍计入官方时间，所以只保留固定 stage
数和一次实际输出复算链。

### L9. Block-diagonal + low-rank 联合输出算子（BDLR-JAQ）

ROAB 后仍存在的跨 block 误差用低秩充分统计表达，而不是恢复完整 `C×C` Gram：

\[
H\approx B_H+U\Lambda U^T,\qquad
D\approx B_D+PV^T,
\]

其中 `B_H/B_D` 是当前 64×64 block，`r=4/8` 的因子由 calibration residual randomized SVD
得到。动态梯度为

\[
g=(B_Hq-B_Da)+U\Lambda(U^Tq)-P(V^Ta).
\]

不增加 Python coordinate sweep；一次性对 15 个合法 mantissa level 计算

\[
\Delta J(c)=2\delta(c)g_i+\delta(c)^2H_{ii},
\]

每行/每 block 只接受一组互不冲突的最佳更新，再写回合法 HiF4 层级。实现全部为 batched
matmul/top-k，在线新增 `O(NCr)`，因此它不是零成本算法；但它直接补上 v138 最关键的跨 block
盲区，且比完整 Gram 的 `O(NC^2)` 可控。v141–v145 实际采用了选列近似（含锚点冻结、
动态-only 与阻尼），完整 panel 的 Linear 均低于 v140，说明**非对称选列梯度不能作为
BDLR 实现**，该具体路线已关闭。若后续重启 L9，只能使用同时具备左右因子的对称/双侧
低秩分解，并先在离线 oracle 中验证再进入 API；当前实施顺序转向 L10 HOQ。

### L10. 层级整体输出量化（HOQ）

HiF4 的 64 通道共享 `scale_factor/lv2/lv3`，单独调 mantissa 或单独扫顶层 scale 都无法表达
层级联动。HOQ 对选中的 block 同时生成固定 `K=4/8` 个完整合法层级候选：

1. 从当前 hierarchy 和输出残差生成有限个 `(scale_factor, lv2, lv3)` 组合；
2. 对每个组合一次向量化求 64 个 mantissa 的最佳合法 code；
3. 用 L9 的真实 `ΔJ` 比较整个 block，而不是相加 operand-local 误差；
4. Weight 在 calibration 直接写入最佳 block；Activation 把候选规则编译成固定小表，一次
   gather/compare 完成，不做多轮 sweep。

旧 255-code oracle 已说明“只扩大顶层 scale”没有大收益；HOQ 的新信息来自**层级联合 + 输出
残差 + ROAB 新坐标系**，不是重新做旧 scale 网格。

### L11. 两轮残差抵消式联合量化（ARCQ）

把 L8–L10 组成固定两轮交替，而不是无限增加 sweep：

1. 用 ROAB 初始化 `Q(W)` 和 calibration `Q(A)`；
2. 计算真实残差 `R=A W^T-Q(A)Q(W)^T`；
3. 固定 `Q(A)`，用 `R` 更新合法 Weight hierarchy/code；
4. 重建 BDLR 的 `H/D`，固定新 `Q(W)` 更新合法 Activation 规则；
5. 再做一次同样的 W/A 更新后停止，最终目标直接使用两折真实输出均值与最差折组合。

误差展开为

\[
R=E_AW^T+AE_W^T-E_AE_W^T,
\]

ARCQ 的目的不是分别把 `E_A`、`E_W` 做到最小，而是让三项在输出空间抵消。这是当前框架
缺失、但 `A@W` 已完全允许后最值得利用的自由度。Linear 0.8 的合理技术路径是
**ROAB 改表示 → HOQ 改层级决策 → ARCQ 联合抵消**；固定参数网格只作为这些新算法内部的
小预算选择，不再被视为主路线。BDLR 选列实现已经由 v141–v145 实测关闭。

## 6. 时间实现原则

官方限制只看六个候选 API 的最终总时间，因此所有算法都同时提供精确研究实现和压缩部署实现。
新协议已经覆盖官方变长 Attention 形状和 250/200 调用数，不再维护另一套 runtime-stress：

1. 解码后的 NVFP4、教师输出、Gram、cross term 和变换候选尽量缓存复用。
2. Weight 更新按输出 row chunk 批量执行。
3. Activation 更新使用增量目标，不为每个码字候选重算完整输出。
4. 完整 H、D 只用于 oracle；提交使用 block、低秩、结构化或因子形式。
5. Attention 不在完整长序列上循环候选。
6. Python coordinate 循环尽量转换为批量 tensor 运算。
7. state 中预存最终需要的 dtype、布局和索引，减少在线转换。
8. 每次实验同时记录六个 API 的调用次数和时间，直接观察精度提升花在了哪里。
9. 168 次 Weight calibration 会放大任何离线逐层成本，250 次 Dynamic A 会放大任何在线
   激活精修；输出监督优先采用缓存 sufficient statistics、row chunk 和一次向量化更新。
10. 本地 `api_total_seconds` 和 `wall_seconds` 不映射为官方时间；它们只用于同设备同 cache
    比较。v084 本地 wall `300.848s` 但官方 `252.563s` 通过，已经证明 wall 不是官方计时。
11. **时间风险更新（v129–v131 均官方 timeout）**：本地 API `<300s` 不再视为提交依据。
    v129 (`248.363s`)、v130 (`295.437s`) 与 v131 (`294.835s`) 均官方 timeout，而 v86
    本地 `299.302s` 却以 `222.7s` 官方通过；后续先按 Attention 算子数量、序列平方项和
    动态调用复杂度做保守压缩，时间父版本采用 v86 级静态路径，再叠加 Linear 精度改动。
    v138 已完成该重构：Linear 保持 `0.5073195`，本地 API `187.935/192.996s`；Attention
    官方分数/时间仍须实际提交验证。

## 7. 实施顺序

按以下顺序执行，但不设置额外晋级门槛：

1. 用只读 cache 在 `official-shape-v1` 上单独复测根 v127，建立当前根的正式新协议记录（已完成）。
2. 移除 dense PAWV，保留 v098 的快速 V 路径；随后再评估低成本 PAWV 摘要。
3. 从 v098/v100 Attention 精度逻辑出发实现固定预算 calibration，复用 v084 的长度预算、
   公共统计缓存和短序列真实复排结构；随后将校准 sweep 固定为 1，API 降至 `248.363s`。
4. 压缩动态 Q/K 的 Gram refine、sweep 和常量创建，并运行完整 450-case 新协议评测；当前
   sweep2 根候选为 API `285.929s`、Attention `0.834256`。
5. 在新协议 tensor/case 上建立 Linear Activation/Weight/Joint 合法 oracle，给出 0.8 的
   直接可达性曲线。
6. 以 v098 的低成本 Linear 路径为实现参考，加入 L1 输出监督权重量化。
7. 实现 L2 block 输出监督激活量化，首先使用一次向量化的 H/D 增量（**已完成：v134**）。
8. 将 Attention 候选循环和动态 Q/K/V 压到 v86 级静态低复杂度，形成时间父版本
   （**已完成：v138，两次本地 API `187.935/192.996s`**）。
9. v139：把现有 Linear `output_gain` 改成输出感知对角补偿；在线仍为原有一次逐通道乘法。
   完整结果 `0.507278 / 0.715942 / 193.389s`，Linear 回退 `0.000041`，**已拒绝**。
10. 在当前 `official-shape-v1` tensor 上重算 legal Activation/Weight/Joint oracle，给出当前
    HiF4 码域与当前 state 表示的真实可达曲线；旧单侧臂只作为结构证据。
11. Linear 首先实现 L8 ROAB，用学习型 reciprocal butterfly **替换**现有 BOAT/FWHT，动态
    stage 数不增加；真实目标直接使用合法 `Q(A)Q(W)^T` 输出误差。**已完成：v140**，
    Linear `0.5073546371`、Attention `0.7159419612`、API `205.365s`，相对 v138
    `+0.0000351323`，已归档并提交。
12. 在 ROAB 上实现 L9 BDLR-JAQ，以 rank `4/8` 补足 `H/D` 跨 block 信息，并将一次 15-level
    更新完全向量化；单独记录新增 Dynamic A 时间。**已验证并关闭：v141–v145**。选列
    rank-4、锚点冻结、仅动态激活及阻尼 `0.02/0.005` 的 Linear 分别为
    `0.281760/0.282559/0.361154/0.506418/0.506256`，均低于 v140；Attention 均为
    `0.715942`，API `204.681–211.460s`。该列式近似不再继续调参。
13. 实现 L10 HOQ，把 scale/lv2/lv3/mantissa 作为完整合法 block 共同比较，不再扩大旧 scale
    网格或增加 Jacobi/sweep 数。
14. 用 L11 ARCQ 做固定两轮 W/A 残差抵消，结束后得到 Linear 结构候选；不做无限交替。
15. Attention 参数槽替换只用于先回收静态 v86 的 `0.719696`；恢复 `0.834` 的主算法是 A6
    reciprocal Gram balancing，用解析 Q/K 互逆 butterfly 替换现有固定 angle/covariance 槽，
    候选数和动态 Gram/sweep 均不增加。
16. 组合最终 Linear 与 Attention 算法，并持续使用完整 `official-shape-v1` 记录精度和六 API
    时间；官方平台仍是 `<300s` 的唯一裁决。

## 9. Linear 0.8 的最终可达性判断

现有证据支持以下结论：

1. 当前 scale/offset/local-Gram/LRH 路线到 0.8 不可行，历史收益已明显递减。
2. 当前最高 Linear 是 v140 的 `0.5073546`；它在 v138 的低复杂度 Attention 时间父版本上
   增加 ROAB-P2 后 API 为 `205.365s`、wall `229.337s`。到 0.8 仍需消除剩余误差的
   `59.41%`，结构性差距仍然很大。
3. 旧 L0 诊断的双侧无损臂为 `1.0`、激活无损单侧臂为 `0.820357`，数学空间没有排除 0.8；
   但激活无损只留下约 `0.02036` 的余量，这些数值必须在新协议 tensor 上重算。
4. 旧权重无损单侧臂只有 `0.704170`，说明只做更强 Weight-GPTQ 明确不够；若保持旧权重，
   到 0.8 近似需要消除 `93.15%` 的 activation-induced 误差。
5. `A@W` 完全放开后，联合输出误差优化能够利用 `E_AW^T`、`AE_W^T`、`E_AE_W^T`
   的抵消关系，这是此前算法没有充分使用的空间。
6. v135–v139 的回退与 v140 的微小正向增益共同说明，局部 warm start、sweep 或连续 gain 不是通往
   0.8 的主路径；下一阶段必须
   改变输出目标的表达能力，而不是在同一个局部目标上增加迭代。
7. 是否能在合法 HiF4 码域中达到 0.8，将由新协议 L0 Joint oracle 直接回答；是否能在官方
   300 秒内达到，则由 ROAB、HOQ、ARCQ 与 v138 时间父版本共同决定。BDLR 选列近似已经由
   v141–v145 的完整 panel 否定。

因此，本计划把 `0.8` 作为正式精度目标执行，但不把它描述成已经证明一定可达。当前可达性判断
是：**当前框架只调参不可达；新的合法联合表示数学上未排除、工程上仍未证明。**技术路径是
**ROAB 改变误差坐标系 + HOQ 联合层级码字 + ARCQ 两轮 W/A 残差抵消**；BDLR 选列方案
已实测关闭。

## 10. Attention 0.834 的最终可达性判断

1. v138 `0.715942` 到 `0.834` 必须消除 `41.56%` 的剩余误差，不属于普通千分位调参。
2. v86 静态路径 `0.719696` 只证明等成本参数/实现至少能回收 `0.003754`；它不能支持
   `0.834` 的结论。
3. 已记录高精度路径中，动态 sweep1 为 `0.828014`、sweep2 为 `0.834256`；虽然这些版本还
   同时有更大的静态候选集，不能视为严格单变量消融，但恢复的量级与 Gram-aware 修正高度一致。
4. PAWV 从 v098 到 v100 只增加约 `0.000044`，所以 V 不是恢复 0.834 的关键，核心是 Q/K
   logit-aware 量化。
5. **只替换 alpha、angle、block size，不可能合理达到 0.834。**严格保持 v138 表示和算子图时，
   目标应设为先恢复 `0.719696`。
6. A6 reciprocal Gram balancing 改变的是表示而不是参数网格：将静态 `G_Q/G_K` 编译进现有
   Q/K 互逆 transform，理论上可以在不增加候选数、动态 Gram 或 sweep 的情况下逼近 Gram
   目标。它是等复杂度恢复大部分精度的唯一明确算法候选，但目前没有证据保证完整达到 0.834。
7. 若 A6 后仍有明显差距，至少一次向量化 Gram-aware code update 才是有证据支撑的恢复路径；
   这会增加 v138 的实际运算量，即使对固定 head_dim 可写成同阶 `O(Td)`，也不能宣称复杂度
   完全不变。

最终结论：**Attention 靠当前参数调节不能等复杂度恢复到 0.834；通过 reciprocal Gram
balancing 这种“替换现有变换”的新表示存在理论可能，但尚未证明。若要求对 0.834 有高把握，
必须接受至少一个被充分向量化的 Gram-aware 动态步骤，并从别处回收时间。**
