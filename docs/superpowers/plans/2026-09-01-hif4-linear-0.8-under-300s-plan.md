## 1. 本计划只有两个目标

1. **提高精度：Linear mean 目标为 `0.8`。** Attention 保留已经取得的有效增益，并通过降低算法复杂度为 Linear 释放时间。
2. **控制时间：官方端到端运行时间严格小于 `300s`。**

本计划不再设置 screen 分数、单 role 回退、rank、block、state 节点数、本地秒数换算等额外晋级门槛。所有实验只记录两类结果：精度变化和运行时间变化。最终保留精度更高且能够满足官方时间限制的实现。

## 2. 当前问题与战略判断

### 2.1 Linear 到 0.8 的数学距离

Linear gain 定义为

\[
g=1-\frac{\operatorname{MSE}_{player}}{\operatorname{MSE}_{standard}}.
\]

v127 的 `g=0.522453`，剩余归一化误差为 `0.477547`；目标 `g=0.8` 对应剩余误差 `0.2`。因此需要消除当前剩余误差的

\[
1-\frac{0.2}{0.477547}=58.12\%.
\]

这不是扩大 offset、rank、block 或 sweep 能完成的局部改进，而是输出目标和求解方式的结构性变化。

五层七 role 诊断给出的单侧理想臂为：

| 诊断臂 | Linear mean |
|---|---:|
| 当前双侧量化 | `0.531887` |
| 权重无损、激活保持当前量化 | `0.714071` |
| 激活无损、权重保持当前量化 | `0.818890` |
| 双侧无损 | `1.0` |

只改善权重不可能到 0.8；只改善激活虽然数学上越过 0.8，但需要接近激活无损。可行主线必须联合控制激活误差、权重误差以及二者在输出空间中的交叉项。

### 2.2 `A@W` 放开后的核心机会

令

\[
Q(A)=A+E_A,\qquad Q(W)=W+E_W.
\]

最终输出误差为

\[
Q(A)Q(W)^T-AW^T
=E_AW^T+AE_W^T+E_AE_W^T.
\]

现有算法主要分别让 `Q(A)` 接近 `A`、`Q(W)` 接近 `W`，没有直接优化上述三项之和。既然 `A@W` 已经可以自由使用，Linear 主目标改为

\[
\min_{Q(A),Q(W)}\|Q(A)Q(W)^T-AW^T\|_F^2.
\]

算法可以主动让激活量化误差和权重量化误差在输出空间中抵消，而不要求两个 operand 各自最接近原值。

### 2.3 Attention 超时的直接原因

v98/v100 在 Attention calibration 中约执行 35 次候选评分，每次都在完整 calibration 序列上重新计算 `QK^T`、softmax 和 `P@V`。其复杂度近似为

\[
O(N_{candidate}\sum_i H_qT_i^2d).
\]

官方 calibration 长度 `[10,128,512,1024,1024]` 的 `\sum T_i^2` 是本地两个 128-token 样本的约 `72.5` 倍。v98/v100 超时是算法复杂度问题，不是实现常数问题。Attention 必须先改成固定预算候选搜索，不能继续在完整长序列上评分全部候选。

## 3. 总体算法结构

新的提交路径分为三个相互配合的部分：

1. **Attention 固定预算搜索**：保留有效的 reciprocal balance、K-centering、rotation 和 GQRB，但候选搜索不再随完整序列长度平方增长。
2. **Linear 输出监督联合量化**：使用 `AW` 直接训练合法 HiF4 `Q(W)`，并让在线 `Q(A)` 直接最小化输出误差。
3. **统一时间压缩**：所有大矩阵目标都转换为缓存统计、低秩因子、分块增量或少量真实输出复算，最终以官方端到端时间为准。

## 4. Attention：保留精度并消除长序列超时

### A1. 固定预算代理搜索

重写 `hif4_calibration_attention` 的候选评分数据流：

1. 完整 calibration Q/K/V 只用于一次线性统计，例如 RMS、二阶矩、head importance 和长度信息。
2. 从每个 calibration sample 确定性采样固定数量 token，构造代理 Q/K/V。
3. alpha、center、signed-Hadamard、rotation、GQRB 全部在代理数据上评分。
4. 代理阶段优先使用 Q/K 重建误差、logit 误差和压缩输出误差，不对所有候选构造完整 `T×T` Attention。
5. 只对代理排序靠前的少量候选执行真实 Attention 输出复算；真实复算仍使用固定长度子样本。
6. 完整 512/1024-token calibration 不进入候选循环，因此候选数不再乘上 `T^2`。

目标复杂度变为

\[
O(N_{proxy}T_{proxy}^2d+N_{short}T_{short}^2d+\sum_iT_id),
\]

其中 `T_proxy`、`T_short` 是固定预算，不随官方最长序列继续增长。

### A2. 缓存候选公共量

对所有候选共用的数据只计算一次：

- dense reference 的采样输出；
- V 的普通 HiF4 结果；
- GQA head 映射；
- RMS ratio；
- Q/K importance 的基础统计；
- rotation signs、Hadamard 和固定 GQRB 矩阵；
- 代理数据的 reshape、head view 和索引。

候选之间只改变 multiplier、center、rotation 或 mixing，不重复解码 NVFP4、不重复建立相同 reference。

### A3. GQRB 低成本化

GQRB 是 v98 相对 v84 的主要 Attention 精度来源，继续保留，但改变选择方式：

1. 固定角度、Hadamard、covariance rotation 作为候选集合；
2. covariance 只在代理 token 上计算；
3. 第一轮用 logit/重建代理排序；
4. 第二轮用固定短序列真实 Attention 排序；
5. 选中的 mixing 写入 CPU state，在线只执行一次小块矩阵乘。

### A4. PAWV 重新定位

当前 PAWV 从 v98 的 `0.842022` 提升到约 `0.842024`，但需要额外完整 probability 和 V 坐标优化。新路径先移除 dense PAWV，确认 Attention 主增益由 GQRB 保留；随后只研究不会恢复全序列候选 `T^2` 成本的形式：

- 代理序列上的位置权重；
- 按长度保存的统计摘要；
- 流式或分块计算的 row importance；
- 直接从 Q/K 二阶统计预测 V row weight。

PAWV 是否保留只由最终精度和总时间结果决定。

### A5. 动态 Q/K/V 向量化

`hif4_dynamic_quantize_q/k/v` 的优化方向：

- 将逐 coordinate 的 15-level 搜索批量化；
- 合并重复的 denominator、importance 和 Gram 转移；
- 根据实际 loss 选择需要精修的 block；
- 比较不同 sweep 数对精度和总时间的实际影响；
- 避免在每个 test sample 中重复创建相同常量 tensor。

## 5. Linear：以 `AW` 为教师目标的联合量化

### L0. 建立合法码域可达性 oracle

Oracle 只用于回答 0.8 是否存在合法 HiF4 解，不作为新的限制：

1. **Activation oracle**：固定当前 `Q(W)`，直接优化合法 `Q(A)`，使 `Q(A)Q(W)^T` 接近 `AW^T`。
2. **Weight oracle**：固定部署 `Q(A)`，直接优化合法 `Q(W)`，使 `Q(A)Q(W)^T` 接近 `AW^T`。
3. **Joint oracle**：交替优化合法 `Q(A)` 和 `Q(W)`，绘制迭代轮数、精度和时间曲线。
4. 分别记录同数据上限、跨 calibration fold 泛化结果和完整 `official-shape-v1` 结果。

该 oracle 会区分三个问题：HiF4 码域是否有能力达到 0.8、calibration 是否能学到该解、以及该解能否在 300 秒内近似实现。

### L1. 输出监督权重量化

固定部署激活 `Z=Q(A)`，对每个输出权重行求解

\[
\min_{w_q\in\mathrm{HiF4}}\|Zw_q-Aw\|_2^2.
\]

实现方式：

1. 对每个 calibration fold 生成实际部署的 `Q(A)`；
2. 缓存教师输出 `Y=AW^T`；
3. 用 `Z^TZ` 和 `Z^TY` 构造离散坐标增量；
4. scale、lv2、lv3、sign、mantissa 作为一个合法层级整体更新；
5. 按输出 row chunk 批量求解，避免长期保存全部输出；
6. 更新一个 block 后增量更新 residual，不重新计算完整 `ZQ(W)^T`；
7. 使用多个 calibration fold 的合并输出目标，减少单样本拟合偏差。

这条路径与现有 Weight-HSDQ 的根本区别是：教师目标是 `AW`，输入是实际 `Q(A)`，因此权重会主动补偿激活量化造成的系统误差。

### L2. 输出监督动态激活量化

固定 `W_q=Q(W)`，对单行激活 `a` 和合法 HiF4 行 `q`，目标为

\[
J(q)=\|qW_q^T-aW^T\|_2^2.
\]

展开得到

\[
J(q)=qHq^T-2qDa^T+\mathrm{const},
\qquad H=W_q^TW_q,\quad D=W_q^TW.
\]

完整 H、D 只用于 oracle。部署实现依次研究以下压缩表达，并记录精度与时间：

- 64×64 block diagonal；
- block diagonal 加低秩残差；
- selected cross-block columns；
- block-circulant/butterfly 结构；
- 直接保存 W、Wq 因子并用稀疏增量恒等式计算真实输出变化。

动态过程先生成普通 HiF4 parent，再用输出目标修改最有价值的码字。候选改变 `delta=q_candidate-q_parent` 时，使用

\[
\Delta J=2\delta(Hq-Da)+\delta H\delta^T
\]

增量计算，而不是为每个候选重新执行 `A@W`。

### L3. 连续输出补偿中心

在离散量化前先求连续目标

\[
a^\star=\arg\min_z\|zW_q^T-aW^T\|_2^2.
\]

不在线求完整逆矩阵，而是在 calibration 阶段学习低秩修正：

\[
a^\star\approx a+aUV^T.
\]

在线以 `O(NKr)` 应用 rank-r 修正，再把修正后的连续中心编码成合法 HiF4，最后由 L2 做离散输出精修。不同 rank 的精度和时间全部进入同一结果表。

### L4. 输出监督等价变换

学习可逆变换 T：

\[
A'=AT^{-1},\qquad W'=WT^T,qquad A'W'^T=AW^T.
\]

T 使用在线成本可控的结构：

- diagonal balance；
- permutation；
- signed-Hadamard；
- butterfly；
- 小块 Givens rotation。

与现有 BOAT 不同，候选 T 直接按量化后的 `Q(A')Q(W')^T` 与 `AW^T` 的误差选择。变换学习只发生在 calibration，在线只应用最终一个 T。

### L5. 联合交替优化

将 L1–L4 组成短链联合优化：

1. 初始化等价变换和普通 Wq；
2. 根据当前 Wq 生成输出监督激活状态；
3. 得到 calibration Q(A)；
4. 用 `AW` 更新合法 Wq；
5. 重新计算 H、D 和低秩补偿；
6. 再更新 Q(A)；
7. 记录每轮精度和时间，选择最终双目标结果。

### L6. 按 Linear 结构分配计算

不同 role 使用同一输出目标，但采用不同压缩方式：

| role/形状 | 主要误差 | 重点算法 |
|---|---|---|
| q、k | 权重侧较强 | 输出监督 Weight-JDRQ、层级整体更新 |
| v | 双侧耦合 | 等价变换加联合优化 |
| o | 激活侧较强 | 低秩激活补偿加输出精修 |
| fc_gate | 双侧均明显 | 联合 Q(A)/Q(W) |
| fc_up | 激活侧主导 | 连续补偿中心和动态输出目标 |
| proj / 宽输入 | 激活侧、跨 block | 低秩/结构化 H、D 和稀疏真实增量 |

路由由 weight shape、calibration 统计和当前输出残差决定，不要求所有层使用相同计算量。

## 6. 时间实现原则

官方限制只看最终总时间，因此所有算法都同时提供精确研究实现和压缩部署实现：

1. 解码后的 NVFP4、教师输出、Gram、cross term 和变换候选尽量缓存复用。
2. Weight 更新按输出 row chunk 批量执行。
3. Activation 更新使用增量目标，不为每个码字候选重算完整输出。
4. 完整 H、D 只用于 oracle；提交使用 block、低秩、结构化或因子形式。
5. Attention 不在完整长序列上循环候选。
6. Python coordinate 循环尽量转换为批量 tensor 运算。
7. state 中预存最终需要的 dtype、布局和索引，减少在线转换。
8. 每次实验同时记录六个 API 的调用次数和时间，直接观察精度提升花在了哪里。

## 7. 实施顺序

按以下顺序执行，但不设置额外晋级门槛：

1. 建立官方变长 Attention runtime-stress 与六 API 时间分解。
2. 完成 Attention 固定预算代理搜索，得到不随 1024-token 候选循环平方增长的版本。
3. 移除 dense PAWV，确认 GQRB 精度和时间；再评估低成本 PAWV 摘要。
4. 建立 Linear Activation/Weight/Joint 合法 oracle，给出 0.8 的直接可达性曲线。
5. 实现 L1 输出监督权重量化。
6. 实现 L2 block 输出监督激活量化。
7. 实现 L3 低秩连续补偿中心。
8. 实现 L4 输出监督等价变换。
9. 组合 L1–L4 做短链联合优化。
10. 对宽 proj 和 FFN activation-heavy 形状增加结构化跨 block 表达。
11. 将 Attention 与 Linear 最佳双目标实现合并，测完整 `official-shape-v1` 和 runtime-stress。
12. 根据官方时间继续压缩实现，最终提交并记录真实分数与时间。

## 9. Linear 0.8 的最终可达性判断

现有证据支持以下结论：

1. 当前 scale/offset/local-Gram/LRH 路线到 0.8 不可行，历史收益已明显递减。
2. HiF4 双侧无损放宽上界为 1.0，激活无损单侧臂为 0.818890，因此数学空间没有排除 0.8。
3. 权重无损单侧臂只有 0.714071，说明必须改变 Q(A)，不能只做更强 Weight-GPTQ。
4. `A@W` 完全放开后，联合输出误差优化能够利用 `E_AW^T`、`AE_W^T`、`E_AE_W^T` 的抵消关系，这是此前算法没有充分使用的空间。
5. 是否能在合法 HiF4 码域中达到 0.8，将由 L0 Joint oracle 直接回答；是否能在官方 300 秒内达到，则由压缩 H/D、低秩补偿和 Attention 固定预算实现决定。

因此，本计划把 `0.8` 作为正式精度目标执行，但不把它描述成已经证明一定可达。技术上最有希望的路径是：**固定预算 Attention + 输出监督等价变换 + 输出监督 Q(A) + 输出监督 Q(W) + 少轮联合离散优化**。
