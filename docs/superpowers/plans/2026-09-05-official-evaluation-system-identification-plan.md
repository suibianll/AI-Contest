# 官方评测规律系统辨识计划

> 状态：PLANNED（仅完成设计，尚未实现或提交探针）
> 日期：2026-09-05
> 官方提交次数：无限制
> 当前计分父：v186 `17599 / 272s`；系统辨识零点：v162 `1001 / 146s`

## 1. 目标

用预注册、可复现的官方提交矩阵回答五个问题：

1. 官方分数在 Linear / Attention、Q / K / V、序列长度和 Linear 形状桶之间是否可加；
2. Q/K/V 的主效应与二阶、三阶交互分别多大；
3. 隐藏评测对短/中/长序列的相对权重；
4. 隐藏模型中不同 Linear 形状族的官方贡献占比；
5. 六 API 本地耗时到官方时间的映射能否由新增正交样本稳定识别。

本计划不尝试从本地 gain 换算官方绝对分，也不通过重复相同 SHA 估计噪声。系统辨识探针
与竞赛根版本分离；除非某个探针实际超过当前父，否则不替换根 `solution.py`。

## 2. 已有官方端点（零新增提交）

只使用同一 `new-weight` cohort：

| 端点 | Linear | Attention | 官方分 / 时间 |
|---|---|---|---:|
| v162 | standard | standard | `1001 / 146s` |
| v163 | v160 | standard | `4587 / 202s` |
| v164 | standard | v160 | `13945 / 204s` |
| v160 | v160 | v160 | `17532 / 232s` |
| v166 | rank-1 | standard | `4590 / 226s` |
| v168 | standard | v160 + A1 | `14005 / 210s` |
| v175 | rank-1 | v160 + A1 | `17594 / 245s` |

两组现成的 2×2 侧向析因给出：

```text
I_v160 = 17532 - 4587 - 13945 + 1001 = 1
I_v175 = 17594 - 4590 - 14005 + 1001 = 0
```

因此“Linear 与 Attention 近似可加”已有两次独立证据。后续实验不重复这两个端点，而把
提交资源用于更细粒度的 Q/K/V、长度和形状分解。

## 3. 统一实验纪律

- 每个探针是独立单文件 `solution.py`，记录 parent、唯一机制差异、SHA256、官方分和时间；
- 不提交相同 SHA、逐位等价实现或只改变空操作/计时的版本；
- 同一实验块一次性预注册全部单元，官方结果返回前不修改分桶、阈值或组合；
- 探针可以低于当前父：其验收目标是辨识参数，不是晋级；状态记为 `PROBE_COMPLETE`，
  不因负分写成算法 `REJECTED`；
- 所有候选先通过六 API、合法 state、有限输出、分桶 reachability、非目标 control、
  脱离仓库单文件导入；
- 每个候选运行 eval-v3 六 shard，并保存六 API 分项时间；预测官方时间必须 `<280s`；
- 官方硬限仍为 `<300s`。任何预测不安全的探针先做等价的低成本机制重构，不直接提交；
- 官方结果只在同 cohort 内比较，禁止与 old-weight 历史绝对分混排。

历史观测显示官方约 `±4` 分属于近零有效噪声带。因禁止重复等价提交，本计划直接采用该
带宽，不另做重复性试验。

## 4. 实验块 A：Attention Q/K/V 完整析因（核心，6 个新提交）

### 4.1 假设

官方 Attention 分数不是三个 operand 的简单独立和；Q/K 应有显著二阶交互，V 更接近独立
主效应。完整 2³ 析因能直接验证这一点。

### 4.2 构造

固定 standard Linear。三个 bit 分别表示 Q、K、V 是否使用 v160 Attention 动态量化路径：

| 单元 | Q | K | V | 提交 |
|---|---:|---:|---:|---|
| `000` | STD | STD | STD | 复用 v162 |
| `100` | v160 | STD | STD | 新提交 |
| `010` | STD | v160 | STD | 新提交 |
| `001` | STD | STD | v160 | 新提交 |
| `110` | v160 | v160 | STD | 新提交 |
| `101` | v160 | STD | v160 | 新提交 |
| `011` | STD | v160 | v160 | 新提交 |
| `111` | v160 | v160 | v160 | 复用 v164 |

八个单元必须共用同一 Attention calibration skeleton；只在三个 dynamic API 的最终路径选择
STD 或 v160。实现前要求本地证明 `000` 与 v162、`111` 与 v164 逐位一致。若做不到，先修正
state adapter，不能用不一致端点冒充析因顶点，也不能重提等价端点。

### 4.3 分析

记官方分为 `S_abc`：

```text
Q   = S100 - S000
K   = S010 - S000
V   = S001 - S000
QK  = S110 - S100 - S010 + S000
QV  = S101 - S100 - S001 + S000
KV  = S011 - S010 - S001 + S000
QKV = S111 - S110 - S101 - S011 + S100 + S010 + S001 - S000
```

产出：主效应占比、交互占比、完整重构误差，以及 Q/K/V 各动态 API 对官方时间的独立斜率。

## 5. 实验块 B：Attention 序列长度权重（核心，4 个新提交）

### 5.1 假设

官方 Attention 分数由若干长度区间加权聚合；v164→v168 的 A1 官方增量 `+60` 可作为
方向已知、时间安全的锚信号。将同一 A1 只部署到互斥长度桶，可恢复隐藏长度权重。

### 5.2 预注册分桶

在 Q/K dynamic API 中按真实 sequence length `n` 同步选择 A1；V 和其余逻辑固定为 v164：

| 桶 | 条件 | 对应本地哨兵 |
|---|---|---|
| `L0` | `n <= 32` | 10 |
| `L1` | `33 <= n <= 256` | 128 |
| `L2` | `257 <= n <= 768` | 512 |
| `L3` | `n > 768` | 1024 |

四个候选各只在一个桶启用 A1。全关闭复用 v164，全开启复用 v168，不重复提交。

### 5.3 分析

记 `S_off=14005-60=13945`，桶提交分为 `S_Lj`：

```text
C_j = S_Lj - S_off
w_j = C_j / 60
R_length = 60 - sum(C_j)
```

`w_j` 是锚机制意义下的官方长度权重。先检查 `R_length`：绝对值 `<=4` 视为与加性一致；
超出后不能立刻解释为样本比例，而要进入确认块 D，排除 A1 在不同长度上的机制异质性。

## 6. 实验块 C：Linear 形状族权重（核心，4 个新提交）

### 6.1 假设

v162→v163 的 Linear 官方贡献为 `3586`。把完全相同的 v160 Linear 路径按互斥权重形状桶
启用，可估计隐藏模型各算子族的计分贡献，并检验官方是否按调用/元素/输出能量非均匀加权。

### 6.2 预注册分桶

设权重形状为 `[rows, cols]`、`r=rows/cols`，按下列顺序互斥匹配：

| 桶 | 条件 | 典型角色解释 |
|---|---|---|
| `W0` | `rows <= 256` | 窄输出 K/V |
| `W1` | `rows > 256 and 0.75 <= r <= 1.33` | 近方阵 Q/O |
| `W2` | `rows > 256 and r > 1.33` | 扩张 gate/up |
| `W3` | 其余 | 收缩/down-proj |

每个候选只在一个桶对 Weight calibration 和对应 dynamic activation 同时启用 v160 Linear，
其余桶使用 v162 standard。分桶必须在本地 168 case 上证明全集覆盖、零重叠和各桶可达。

### 6.3 分析

记桶分数 `S_Wj`、零点 `S0=1001`、全开启贡献 `3586`：

```text
C_j = S_Wj - S0
w_j = C_j / 3586
R_shape = 3586 - sum(C_j)
```

同时比较本地 case 数、元素数、reference energy、STD MSE 与官方 `w_j`，检验官方更接近
“按调用等权”“按元素加权”“按能量加权”还是隐藏任务精度权重。

## 7. 实验块 D：条件确认（非默认执行）

只在 B 或 C 的重构残差实质超出噪声带时启动，不围绕结果调阈值：

1. **长度第二锚**：用固定的 A4 moment-threshold 退化机制复现同一 `L0–L3` 分桶；
   全开启端点已有 v171，相对 v168 为 `−348`。若两锚归一化权重一致，长度权重解释成立；
   若不一致，说明官方增量主要由机制×长度交互决定。
2. **成熟父微扰 2×2**：仅当两个已保留研究机制都通过 `<280s`，提交
   Linear static act-order、Attention block4 Matrix-Smooth 及其组合，共 3 个单元，
   复用 v186 为 `00`，检验小效应在成熟父上是否仍侧向可加。

不执行参数邻域、角度、收缩或阈值扫描；D 是预先定义的第二锚/交互确认，不是优化搜索。

## 8. 官方时间模型更新（不新增纯计时提交）

每个 A/B/C 探针同步记录：

```text
W_calib, A_calib, dyn_act, dyn_q, dyn_k, dyn_v, T_official
```

拟合并对比三种模型：

1. 现有聚合模型：`dyn_qkv` 合并；
2. 分 operand OLS：Q/K/V 分开；
3. 非负约束回归：除截距外所有耗时系数 `>=0`，消除现模型 `dyn_qkv=-1.58` 的共线性伪象。

采用 leave-one-family-out 验证（A、B、C 各作为一次整块 holdout），报告 MAE、最大绝对误差、
R² 和 280s 门禁误放/误杀。只有新模型 MAE 明显低于当前 `10.1s` 且各折稳定，才更新
AGENTS.md 中的时间公式。

## 9. 判定阈值

对任一可加重构残差 `R`：

- `|R| <= 4`：与官方整数化噪声带内的可加性一致；
- `4 < |R| <= max(20, 0.01*|总效应|)`：弱交互，启动对应确认块；
- `|R| > max(20, 0.01*|总效应|)`：实质非加性，不再用简单贡献比例解释。

对零/近零桶，必须同时检查本地 reachability。官方零且本地有明确锚效应才可解释为隐藏权重低；
本地也为零只能说明探针未覆盖该桶。
