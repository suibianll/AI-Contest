# v248（L-EM K=3）把 L-EM 下降从两轮加到三轮

**类型**：**分数候选**（非等价改动）。
**父**：v245 根，SHA `738d2b3617a3fa287524c9f9558a0a43b3af11076bc94a00d0e38a112e45521f`（519334 B）。
**候选**：SHA `aa9658d8da7dc07041c15b785c66ecdadb9b774b50247f43bd52ab1f8e0b7d11`（519790 B，+456 B）。
**官方**：`unregistered/NA`，**待提交**。

---

## 改动

一行常量：`_EM1_PASSES = 2` → `3`。

## 为什么是这一行

`solution.py:11933` 起的注释自己写明 K=2 是**被时间论证定的**，不是下降收敛了：

> Local measurement cannot settle which convention holds, so L-EM3 ships this arm — the L-EM2 card's
> own pre-registered primary — and lets the official machine decide. **No fixed choice of the
> mechanism changes; only the pass count.**

而 K 的历史定价是本项目**最大的单笔增益**：

| 版本 | 机制 | 官方 |
|---|---|---|
| v202 根 | — | `18053` |
| v230 | L-EM2（K=1） | **`18428`**（**+375**） |
| v231 | L-EM3（K=2） | **`18518`**（对 v230 **+90**） |

**K=1→2 在本地六 shard 上是 `+0.027507`** —— 比任何 Attention 机制大**一个数量级**。

而 v243–v245 三张 Attention 卡**逐字节等价地**回收了约一次 Attention 校准调用的四分之一。
**这张卡就是把那笔余量花在 Linear 侧。**

## 口径与风险

1. **本地面板对官方无预测力**（本项目已多次实测：VK 本地 `+0.0046` → 官方 `−307`；
   A-MC1 本地 `+0.0149` → 官方 `−2`）。**本卡的 `+0.0134` 同样不能外推官方。**
   - **但本卡与那两个反例有一个结构性差别**：L-EM 这一类**是本项目唯一有官方收益记录、
     且本地读数可预测官方的机制类别**（L-EM2 `+375`、L-EM3 `+90`，本地六 shard 分别为
     `+0.079454` / `+0.027507`，方向与量级都迁移了）。**这正是选它而不是再做一个 Attention 机制的理由。**
2. **时间**：+4.18% 只测在 GPU 上；官方是鲲鹏 920B CPU 且该机 `cuda.is_available()` 为假。
   **不预测官方秒数、不换算系数。** 若官方因时间超限，本卡判负。
3. **未测 K=4**。第三轮仍接受 33166 组，**说明尚未收敛**；K=4 可能还有收益。
   留作下一张（先在面板上测，再决定是否归档）。
