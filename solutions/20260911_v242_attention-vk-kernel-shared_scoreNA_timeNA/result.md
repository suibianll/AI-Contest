## 与 v241 的唯一差别

| | v241 | v242 |
|---|---|---|
| 核的粒度 | **每 Q head 一个**（16 个） | **每 KV 组一个**（4 个） |
| 目标 | `Σ_g Σ_{h∈g} Σ_t (Σ_k w_h[t−k]δ)²` | 同式，组内 `w_h` 相同 |
| 每轮带状运算 | 16 次 | **4 次** |
| V API 单次成本 Δ | +0.0666 s | **+0.0117 s** |

**共享不是精度折让，是重参数化**：组内 4 个 head 若共享 `w_g`，目标化为
`4·Σ_t (Σ_k w_g[t−k]δ)²`——**最小化点与逐 head 版完全相同**，只是每组的带状运算从 4 次降到 1 次。

## 与 VK-3 预测的对账（2026-09-11 补）

**面板的 `delta_mean` 是增益单位**（`1 − MSE_P/MSE_S`），不是 MSE 比值。换算：

```
Δgain = +0.0045   →   Δ(MSE_P/MSE_S) = −0.0045
当前 MSE_P/MSE_S = 1 − 0.5340 = 0.466
相对变化 = 0.0045 / 0.466 ≈ 0.98%
```

而 VK-3 在留出校准窗上量到的 V 侧收益是 **−0.986%**（10/12 窗）。
**两者吻合到 0.01 个百分点以内——机制几乎无损地转移到了面板上。**

这条纠正了一个容易犯的错：把增益单位读成 MSE 比值，会得出"只转移了 10%"的相反结论。
**增益单位与 MSE 比值之间差一个 `1/(1−gain)` 因子，在 gain≈0.53 时接近 2.** 
本仓库任何跨口径的比较都必须先换算。
